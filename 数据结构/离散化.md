# 离散化

## 一、核心作用

- 把**大数、负数、稀疏数** → 映射成 **1,2,3… 连续小下标**
- 只保留**相对大小**，方便开数组、做差分 / 树状数组 / 线段树

## 二、完整四步

1. 复制原数组（不破坏原数据）
2. 排序
3. 去重（sort + unique）
4. 用 `lower_bound` 二分映射

## 三、完整模板（含映射 + 还原查找）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    // 原数组
    vector<int> a = {100, -5, 99999, 100, -5, 0};

    // ===== 1. 离散化预处理 =====
    vector<int> b = a;                // 复制
    sort(b.begin(), b.end());         // 排序
    b.erase(unique(b.begin(), b.end()), b.end()); // 去重

    // ===== 2. 原数 → 离散下标 =====
    vector<int> res(a.size());
    for (int i = 0; i < a.size(); i++) {
        res[i] = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;
    }

    // ===== 3. 离散下标 → 还原原数（你要的查找）=====
    auto get_original = [&](int id) {
        return b[id - 1]; 
    };

    // ===== 输出演示 =====
    cout << "原数组：";
    for (int x : a) cout << x << " "; cout << endl;

    cout << "离散后：";
    for (int x : res) cout << x << " "; cout << endl;

    cout << "还原 res[0]：" << get_original(res[0]) << endl;

    return 0;
}
```

## 四、极简口诀版（直接记）

```cpp
// 离散化
b = a;
sort(b);
unique(b);

// 映射
for (int &x : a)
    x = lower_bound(b, x) - b + 1;

// 还原查找
原数 = b[离散ID - 1];
```

## 五、对应关系

- 原数 x → 离散 ID：`lower_bound(b, x) - b + 1`
- 离散 ID → 原数 x：`b[ID - 1]`
- b 数组：去重排序后的 “字典”
