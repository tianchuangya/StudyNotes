# 二叉树的建立题型模板总结（数组版）

### 通用结构（所有模板都用这个）

```cpp
#include <iostream>
#include <string>
using namespace std;

const int MAXN = 10000;
char tree[MAXN];   // 数组存二叉树
string pre, in, post; 
```

### 模板1：已知父节点、左孩子、右孩子

类似洛谷 P1305 新二叉树，注意这类输入并不保证输入顺序（不满足前序，或者后序顺序输入）

解题思路：利用左右、节点数组left，right，root三个存储利用root的值对应下表键值去存储左节点和右节点，反之利用当前节点root的值去查找左右孩子的值

```textile
输入：
节点 左 右
A B C
B D #
C # E
D # #
E # #
```

```cpp

char leftChild[128];   // 直接用字符当下标，比如 leftChild['A']
char rightChild[128];
int main() {
  int n; char root; cin >> n;
    for (int i = 0; i < n; ++i) {
        char node, l, r; cin >> node >> l >> r;
        if (i == 0) root = node;    //第一行是根
        leftChild[node] = l;
        rightChild[node] = r;
    }
   preorder(root);
   return 0;
}
```

### 模板二：已知：完全二叉树层次遍历

直接按层给一串节点，空节点用 0 或 # 表示。

例如：

```
A B C D # E
```

```cpp
int main() {
    string s;
    cin >> s;
    for (int i = 0; i < s.size(); i++) {
        tree[i + 1] = s[i];   // 从 1 开始存
    }
    // 直接遍历
    return 0;
} 
```

### 模板3：扩展二叉树前序遍历（蓝桥杯最爱）

```cpp

// 参数：
// s：扩展前序字符串
// pos：当前处理到第几个字符
// u：当前节点在数组里的编号int build(string &s, int pos, int u) {
    
int build(string &s, int pos, int u){
    char c = s[pos];       // 当前位置取字符
    if (c == '#') {
        return pos + 1;    // 空节点，返回下一个位置
    }

    tree[u] = c;           // 存到数组 u 位置
    pos++;                 // 指针后移

    // 建左孩子，pos 会被更新
    pos = build(s, pos, u * 2);
    // 建右孩子，pos 继续往后走
    pos = build(s, pos, u * 2 + 1);

    return pos; // 返回最终处理到的位置
}
```

### 模板4：给 n 对关系：编号 x 的左 / 右孩子是 y

```cpp
输入：
5
1 2 3
2 4 0
3 0 5
4 0 0
5 0 0
```

```cpp
const int MAXN = 1000;
int lc[MAXN], rc[MAXN];
int n;

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int x, l, r;
        cin >> x >> l >> r;
        lc[x] = l;
        rc[x] = r;
    }
    // 遍历用 dfs
    return 0;
} 
```

### 模板 5：前序 + 中序 → 建树

```cpp
void build_pre_in(int preL, int preR, int inL, int inR, int u) {
    if (inL > inR) return;
    char root = pre[preL];
    tree[u] = root;

    int k = inL;
    while (in[k] != root) k++;
    int left = k - inL;

    build_pre_in(preL+1, preL+left, inL, k-1, u*2);
    build_pre_in(preL+left+1, preR, k+1, inR, u*2+1);
}
```

### 模板 6：中序 + 后序 → 建树

```cpp
void build_in_post(int inL, int inR, int postL, int postR, int u) {
    if (inL > inR) return;
    char root = post[postR];
    tree[u] = root;

    int k = inL;
    while (in[k] != root) k++;
    int left = k - inL;

    build_in_post(inL, k-1, postL, postL+left-1, u*2);
    build_in_post(k+1, inR, postL+left, postR-1, u*2+1);
}
```
