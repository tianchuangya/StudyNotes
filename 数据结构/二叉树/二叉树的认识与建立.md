# 二叉树的认识与建立

### 一、树基本介绍

   树是一种数据结构，它是由n（n>=1）个有限节点组成一个具有层次关系的集合。

![](https://i-blog.csdnimg.cn/blog_migrate/8f95571559605bca995ce1e094b95698.png)

   把它叫做“树”是因为它看起来像一棵倒挂的树，也就是说它是根朝上，而叶朝下的。它具有以下的特点：

          1.每个节点有零个或多个子节点;

          2.没有父节点的节点称为根节点;

          3.每一个非跟节点有且仅有一个父节点;

          4.除了根节点以外，每个子节点可以分为多个不想交的子树。

### 二、树的基本术语

若一个节点有子树，那么该节点称为子树根节点的“双亲“，子树的跟是该节点的“孩子”。有相同双亲的节点互为“兄弟节点”。一个节点的所有子树上的任何节点都是该节点的后裔。从根节点到某个节点的路径上的所有节点都是该节点的祖先。

    节点的度：节点拥有的子树的数目。

             叶子：度为零的节点。
    
             分支节点：度不为零的节点。
    
             树的度：树中节点的最大的度。
    
             层次：根节点的层次为1，其余节点的层次等于该节点的双亲节点加1。
    
             树的高度：树中节点的最大层次。
    
             无序数：如果树中节点的各子树之间的次序是不重要的，可以交换位置。
    
             有序数：如果树中结点的各子树的次序是重要的，不可以交换位置。
    
             森林：0个或多个不相交的树组成。对森林加上一个跟，森林即成为树；删去跟，树即成为森林。

### 三、二叉树定义：

#### 定义：

###### 二叉树是每个节点最多有两个子树的树结构。它有五种基本形态：二叉树可以是空集；根可以有空的左子树或右子树；活着左、右子树皆为空。

3、二叉查找树

        二叉查找树（Binary Search Tree）：对树上**任意一个节点**：

- 它的**左子树**所有节点值 **< 它本身**
- 它的**右子树**所有节点值 **> 它本身**
- 满足层序遍历是升序

左右子树也都是二叉查找树

### 五、二叉树的遍历

##### 1、先序遍历

![Pre](https://i-blog.csdnimg.cn/blog_migrate/bc52a55c76e4a68ee7d1dcb76a324d00.gif#pic_center)

递归法：

```cpp
void PreOrder(BiTree T){//先序遍历二叉树（递归）
    if(T != NULL){
        visit(T);//访问根节点
        PreOrder(T->leftChild);//递归遍历左子树
        PreOrder(T->rightChild);//递归遍历右子树
    }
}//设二叉树的结点有 n个，则时间复杂度和空间复杂度都为 O(n)

```

    栈：

```cpp
void PreOrder2(BiTree T){//先序遍历二叉树（非递归）
    InitStack(S);//初始化栈 S
    BiTree p = T;//p为用来遍历的指针
    while(p || !IsEmpty(S)){//p不空或栈不空时进入循环
          if(p){//一路向左
              visit(p);//访问当前结点
              Push(S, p);//当前结点入栈
              p = p->leftChild;//若左孩子不空，则一直向左走
          }
          else{//出栈，并转向出栈结点的右子树
              Pop(S, p);//栈顶元素出栈
              p = p->rightChild;//向右子树走，p赋值为当前结点的右孩子
          }//返回 while循环继续进入 if-else语句
    }
}

```

3、后序遍历

![Post](https://i-blog.csdnimg.cn/blog_migrate/ddf610b328147305bea4bc6114000c45.gif#pic_center)

递归：

```cpp
void PostOrder(BiTree T){//后序遍历二叉树（递归）
    if(T != NULL){
        PostOrder(T->leftChild);  //递归遍历左子树
        PostOrder(T->rightChild); //递归遍历右子树
        visit(T);                 //访问根节点
    }
}//设二叉树的结点有 n个，则时间复杂度和空间复杂度都为 O(n)
```

栈：

```cpp
void PostOrder2(BiTree T){//后序遍历二叉树（非递归）
    InitStack(S);        //初始化栈 S
    BiTree p = T;        //p为用来遍历的指针
    BiTree last = NULL;  //记录上一个被访问的结点，防止重复访问右孩子
    while(p || !IsEmpty(S)){//p不空或栈不空时进入循环
        if(p){//一路向左
            Push(S, p);  //当前结点入栈
            p = p->leftChild;//若左孩子不空，则一直向左走
        }
        else{//查看栈顶，判断右子树是否已访问
            GetTop(S, p); //获取栈顶元素，不出栈
            if(p->rightChild && p->rightChild != last){
                //右孩子存在且未被访问，转向右子树
                p = p->rightChild;
            }
            else{
                Pop(S, p);   //栈顶元素出栈
                visit(p);    //访问出栈结点
                last = p;    //标记当前结点为已访问
                p = NULL;    //置空，继续取栈顶
            }
        }//返回 while循环继续进入 if-else语句
    }
}
```
