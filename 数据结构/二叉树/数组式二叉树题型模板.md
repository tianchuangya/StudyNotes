### 模板1-2：三种遍历输出（栈模拟法）推荐

```cpp
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

const int N = 1000002;
int l[N], r[N];
vector<int> pre, ino, post;
int n;

// 前序：根 → 左 → 右
void preorder() {
    stack<int> st;
    st.push(1);
    while (!st.empty()) {
        int u = st.top();
        st.pop();
        pre.push_back(u);
        if (r[u]) st.push(r[u]);
        if (l[u]) st.push(l[u]);
    }
}

// 中序：左 → 根 → 右
void inorder() {
    stack<int> st;
    int u = 1;
    while (u || !st.empty()) {
        while (u) {
            st.push(u);
            u = l[u];
        }
        u = st.top();
        st.pop();
        ino.push_back(u);
        u = r[u];
    }
}

// 后序：左 → 右 → 根（带访问标记）
void postorder() {
    stack<pair<int, bool>> st;
    st.push({1, false});
    while (!st.empty()) {
        auto p = st.top();
        st.pop();
        int u = p.first;
        bool vis = p.second;
        if (vis) {
            post.push_back(u);
        } else {
            st.push({u, true});
            if (r[u]) st.push({r[u], false});
            if (l[u]) st.push({l[u], false});
        }
    }
}


```

##### 简单讲下栈的思路

###### （1）前序

- 根先出栈、输出
- 先压右、再压左 → 保证左先遍历

###### （2）中序

- 一路向左走到头
- 回溯时输出根
- 再去右子树

###### （3）后序（最常用写法）

- 栈里存 `{节点, 是否访问过}`
- 第一次遇到：标记为已访问，再把右、左、根依次压栈
- 第二次遇到（`vis=true`）：输出

### 模板3：求二叉树高

```cpp
int get_height(int u) {
    if (!tree[u]) return 0;
    int lh = get_height(u * 2);
    int rh = get_height(u * 2 + 1);
    return max(lh, rh) + 1;
}
```

```cpp
int get_leaf(int u) {
```

### 模板6：求度为 1 的节点（只有 1 个孩子）

```cpp
int get_degree1(int u) {
    if (!tree[u]) return 0;
    int cnt = 0;
    // 有左无右 或 有右无左
    if ((tree[u*2] && !tree[u*2+1]) || (!tree[u*2] && tree[u*2+1]))
        cnt = 1;
    return cnt + get_degree1(u*2) + get_degree1(u*2+1);
}
```

```cpp
int get_degree2(int u) {
```

### 模板8：求二叉树直径（树中最远两点距离）

```cpp
int ans = 0;
int dfs(int u) {
    if (!tree[u]) return 0;
    int l = dfs(u*2);
    int r = dfs(u*2+1);
    ans = max(ans, l + r);
    return max(l, r) + 1;
}
// 调用后 ans 就是直径
```
