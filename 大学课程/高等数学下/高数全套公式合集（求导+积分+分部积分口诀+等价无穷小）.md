# 高数全套公式合集（求导\+积分\+分部积分口诀\+等价无穷小）

## 一、基本求导公式

### 1\. 常数与幂函数

1. $(C)' = 0$（$C$为常数）

2. $(x^\mu)' = \mu x^{\mu-1}$

3. $(\frac1x)' = -\frac{1}{x^2}$，$(\sqrt{x})' = \frac{1}{2\sqrt{x}}$

### 2\. 指数、对数函数

1. $(e^x)' = e^x$

2. $(a^x)' = a^x \ln a \quad(a>0,a\neq1)$

3. $(\ln x)' = \frac1x$

4. $(\log_a x)' = \frac{1}{x\ln a}$

### 3\. 三角函数

1. $(\sin x)' = \cos x$

2. $(\cos x)' = -\sin x$

3. $(\tan x)' = \sec^2 x$

4. $(\cot x)' = -\csc^2 x$

5. $(\sec x)' = \sec x \tan x$

6. $(\csc x)' = -\csc x \cot x$

### 4\. 反三角函数

1. $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$

2. $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$

3. $(\arctan x)' = \frac{1}{1+x^2}$

4. $(\text{arccot }x)' = -\frac{1}{1+x^2}$

## 二、导数四则运算法则

设 $u=u(x),\ v=v(x)$ 均可导：

1. 和差：$(u\pm v)' = u' \pm v'$

2. 乘积：$(uv)' = u'v + uv'$

3. 商：$\displaystyle \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2} \quad(v\neq0)$

推论：$(Cu)' = Cu'$（$C$常数）

## 三、复合函数求导（链式法则）

若 $y=f(u),\ u=g(x)$，则
$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$
多层复合：$y=f(u),u=g(v),v=h(x)$
$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dv}\cdot\frac{dv}{dx}$

## 六、三大积分法则

### 1\. 线性性质

$\int \big[k_1f(x)+k_2g(x)\big]dx = k_1\int f(x)dx + k_2\int g(x)dx$

### 2\. 第一类换元（凑微分）

$\int f\big[\varphi(x)\big]\varphi'(x)dx = \int f(u)du,\quad u=\varphi(x)$

### 3\. 第二类换元（变量代换）

$\int f(x)dx = \int f\big[\varphi(t)\big]\varphi'(t)dt,\quad x=\varphi(t)$

### 4\. 分部积分公式

$\int u,dv = uv - \int v,du$

#### 选 u 口诀：**反、对、幂、指、三**

优先级从高到低，靠前函数优先设为 $u$：

1. 反三角函数（arcsin/arccos/arctan…）

2. 对数函数（$\ln x,\log_a x$）

3. 幂函数（$x,x^2,x^3\cdots$）

4. 指数函数（$e^x,a^x$）

5. 三角函数（$\sin x,\cos x,\tan x\cdots$）

## 七、常用等价无穷小（$x\to0$ 时）

1. $\sin x \sim x$

2. $\tan x \sim x$

3. $\arcsin x \sim x$

4. $\arctan x \sim x$

5. $e^x - 1 \sim x$

6. $\ln(1+x) \sim x$

7. $1-\cos x \sim \dfrac12 x^2$

8. $(1+x)^\alpha - 1 \sim \alpha x$（$\alpha$ 任意常数）

9. $a^x - 1 \sim x\ln a$

10. $\sin^k x \sim x^k,\ \tan^k x \sim x^k$

### 拓展替换规则

1. 整体替换：若 $\square\to0$，则 $\sin\square\sim\square,\ e^\square-1\sim\square$ 全部成立；

2. 仅乘除可替换，加减不能直接替换（需泰勒展开修正）。
