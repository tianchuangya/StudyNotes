# 无穷级数 完整版期中复习总结

## 一、常数项级数基础

### 1\. 收敛定义

部分和极限存在 → 级数收敛；否则发散。

### 2\. 必要条件（第一步必看）

$\lim_{n\to\infty}u_n \neq 0 \implies \text{直接发散}$
极限为 0：**不能判定**，继续用别的方法。

## 二、正项级数判别

只含正数项 $\sum u_n\ (u_n\ge0)$

1. **两个基准级数（用来对比）**

- 等比级数 $\boldsymbol{\sum q^n}$：$|q|<1$ 收敛，$|q|\ge1$ 发散

- p 级数 $\boldsymbol{\sum \dfrac{1}{n^p}}$：$p>1$ 收敛，$p\le1$ 发散

2. **比较判别法**
大收小收，小发大发；跟 p 级数、等比级数比对。

3. **比值判别法（有阶乘、**$n$** 指数优先）**
$\rho=\lim_{n\to\infty}\frac{u_{n+1}}{u_n}$
$\rho<1$ 收敛；$\rho>1$ 发散；$\rho=1$ 失效。

4. **根值判别法（有 **$n$** 次方优先）**
$\rho=\lim_{n\to\infty}\sqrt[n]{u_n}$
判别规则和比值完全一样。

## 三、交错级数

形式：$\boldsymbol{\sum (-1)^n u_n,\ u_n>0}$
**莱布尼茨判别法（两个条件同时满足就收敛）**

1. $u_n$ 单调递减

2. $\lim\limits_{n\to\infty}u_n=0$

## 四、绝对收敛 \&amp; 条件收敛

1. 加绝对值后收敛 → **绝对收敛**

2. 加绝对值发散，原交错级数收敛 → **条件收敛**

## 五、幂级数 收敛半径 / 区间 / 收敛域

标准形式：$\boldsymbol{\sum a_n x^n}$

1. **收敛半径**
$\boldsymbol{R=\lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right|}$

2. **三个概念区分**

- 收敛半径：一个数值 $R$

- 收敛区间：开区间 $\boldsymbol{(-R,R)}$，**不含端点**

- 收敛域：$(-R,R)$ 基础上，**单独判别 **$x=\pm R$** 端点敛散性**，收敛就闭区间，发散就开区间

3. **做题固定三步**
① 求半径$R$  ② 写收敛区间$(-R,R)$  ③ 逐个判端点，定收敛域。

## 六、应试总口诀

通项不为 0 直接散；
正项比值根值选，阶乘比值、次方根值；
交错莱布尼茨判；
幂级数先求半径，区间直接开区间，收敛域再把端点挨个看。
