# 线性方程组的解法核心知识点总结

## 齐次线性方程组 Ax=0

#### 一、解的存在性判定

对于 n 元齐次线性方程组 Am×n​x=0：

- 若系数矩阵的秩 r(A)=n：方程组**只有零解**（唯一解）；
- 若 r(A)<n：方程组**有非零解**（无穷多解）。
