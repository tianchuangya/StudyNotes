# 0、简介

## “script” 标签

- 使用 `<script>` 标签将 JavaScript 程序插入到 HTML 文档的任何位置。
- 浏览器遇到 `<script>` 标签时，其中的代码会自动运行。

## 现代的标记 (markup)

- **type 特性**：在老 HTML4 标准中要求，如 `type="text/javascript"`，现代 HTML 中不再必需。现在用于 JavaScript 模块。
- **language 特性**：用于显示脚本语言，现已过时，因为默认就是 JavaScript。
- **脚本前后的注释**：用于古老浏览器隐藏 JavaScript 代码，现代开发中已不再使用。

## 外部脚本

- 通过 `src` 特性引入外部脚本文件：
  
  ```html
  <script src="/path/to/script.js"></script>
  ```
- 路径可以是：
  - **绝对路径**：从网站根目录开始
  - **相对路径**：如 `src="script.js"` 或 `src="./script.js"`
  - **完整 URL**：引用外部 CDN 上的脚本
- **多个脚本**：使用多个 `<script>` 标签引入
- **重要注意事项**：
  - 一个 `<script>` 标签不能同时有 `src` 特性和内部代码
  - 浏览器会缓存外部脚本文件，提高后续页面加载速度

## 总结

1. 使用 `<script>` 标签将 JavaScript 代码添加到页面
2. `type` 和 `language` 特性不是必需的
3. 外部脚本通过 `<script src="path/to/script.js"></script>` 插入
4. 复杂的脚本建议放在外部文件中，简单脚本可内嵌在 HTML 中
5. 本教程使用浏览器作为 JavaScript 运行环境，但 JavaScript 也可在其他环境（如 Node.js）中运行
