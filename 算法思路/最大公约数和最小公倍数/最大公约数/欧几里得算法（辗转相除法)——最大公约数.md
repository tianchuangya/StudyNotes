# **最大公约数**：

### **辗转相除法**：

**概念**：若整数 `d` 能同时整除 `a` 和 `b`（即 `a % d = 0` 且 `b % d = 0`），则 `d` 是 `a` 和 `b` 的<span style="color:#ee4c2e">**公约数**</span>；所有公约数中最大的那个，就是<span style="color:#ee4c2e">**最大公约数**</span>，记为 `gcd(a, b)`。

如果a > b，那么a和b的最大公约数，等于<span style="color:#ee4c2e">**b**</span>和<span style="color:#ee4c2e">**a除以b的余数（r）**</span>的最大公约数。

用数学语言表达：

gcd(a,b)=gcd(b,a mod b)

其中 `a mod b` 是a除以b的余数。

###### **为什么这样成立**

假设：

- a ÷ b = q … r （商q，余数r）

- 即：<span style="color:#209fff">a=b×q+r</span>

**推理**：

- 设<span style="color:#209fff">d</span>是a和b的公约数（d能整除a，也能整除b）

- 因为 <span style="color:#209fff">r=a−b×q</span>，而d能整除a和b

- 所以d也能整除r（因为它是两个能被d整除的数的线性组合）

- 反之，如果d是b和r的公约数，d也能整除 <span style="color:#209fff">a=b×q+r</span>

- **结论**：<span style="color:#ee4c2e">**a和b的公约数集合 = b和r的公约数集合**</span>

- 所以它们的**最大**公约数也相同

**例子**：求<span style="color:#9221ff">gcd(48, 18)</span>

1. 48 ÷ 18 = 2 … <span style="color:#9221ff">12</span> → gcd(48, 18) = gcd(18, <span style="color:#9221ff">12</span>)

2. 18 ÷ 12 = 1 … <span style="color:#9221ff">6</span> → gcd(18, 12) = gcd(12, <span style="color:#9221ff">6</span>)

3. 12 ÷ 6 = 2 … <span style="color:#9221ff">0</span> → gcd(12, 6) = gcd(6, <span style="color:#9221ff">0</span>) = <span style="color:#9221ff">6</span>

**代码实现**：

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;  // 计算余数
        a = temp;   // 更新a为原来的b
    }
    return a;
}
```

<span style="color:#32833a">**备注**：这是最常用的循环实现方式，时间复杂度为O(log min(a, b))。</span>

### 多个数求最大公约数：

 <span style="color:#209fff">以第一个数为初始值，遍历剩余所有数，两两递推求 GCD，本质是复用 “两数 GCD 公式（欧几里得算法）” 逐步收敛到最终结果。</span> 

代码实现：

```cpp
int gcd(int a, int b) {
    a = abs(a);
    b = abs(b);
    while (b) {
        int c = a % b;
        a = b;
        b = c;
    }
    return a;
}

// 多个数的GCD（数组arr，长度n）
int gcds(int arr[], int n) {
    int res = arr[0];  // 初始值取第一个数
    for (int i = 1; i < n; i++) {  // 遍历剩余数
        res = gcd(res, arr[i]);      // 两两递推求GCD
        if (res == 1) break;       // 优化：GCD=1时无需继续计算
    }
    return res;
}
```
