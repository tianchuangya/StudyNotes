# **更相减损术**：

### **一、核心概念**：

更相减损术是中国古代求<span style="color:#ee4c2e">**两个正整数最大公约数**</span>的算法，核心思想是：若两个数不相等，用较大数减去较小数，得到的差与原来的较小数组成新的数对；重复此操作，直到数对中的两个数相等，这个相等的数就是<span style="color:#ee4c2e">**最大公约数**</span>，记为 `gcd(a, b)`。
用数学语言表达：

- 若 `a > b`，则 `gcd(a, b) = gcd(b, a - b)`；

- 若 `a < b`，则 `gcd(a, b) = gcd(a, b - a)`；

- 若 `a = b`，则 `gcd(a, b) = a`（或 `b`）。
  
  ##### **算法原理推导**
  
  假设：
  
  设<span style="color:#209fff">d</span>是`a`和`b`的公约数（`d`能整除`a`，也能整除`b`）；
  
  令<span style="color:#209fff">c = |a - b|</span>（`a`与`b`的差值的绝对值）。

### **推理：**

因为 `d` 能整除`a`和`b`，所以`d`也能整除`a - b`（或`b - a`），即`d`是`b`和`c`（或`a`和`c`）的公约数；

反之，若`d`是`b`和`c`（或`a`和`c`）的公约数，那么`d`也能整除`b + c`（或`a + c`），即`d`也是`a`和`b`的公约数；

**结论**：<span style="color:#ee4c2e">**a和b的公约数集合 = 差值与较小数的公约数集合**</span>；

因此它们的**最大**公约数也相同。

###### **优化补充**

若两个数都是<span style="color:#209fff">偶数</span>，可先同时除以<span style="color:#9221ff">2</span>，并记录除以2的次数；最后将得到的相等数乘以记录的2的幂次，即为最终最大公约数（此优化可减少减法次数）。

### **二、举例说明**：

求<span style="color:#9221ff">gcd(48, 18)</span>

1. 48 和 18 均为偶数，先同时除以2 → 数对变为(24, 9)，记录除以2的次数：1次；

2. 24 > 9，24 - 9 = 15 → 新数对：(9, 15)；

3. 15 > 9，15 - 9 = 6 → 新数对：(9, 6)；

4. 9 > 6，9 - 6 = 3 → 新数对：(6, 3)；

5. 6 > 3，6 - 3 = 3 → 新数对：(3, 3)；

6. 数对相等，结果为 3 × 2¹ = <span style="color:#9221ff">6</span>。
   再举一例：求<span style="color:#9221ff">gcd(81, 54)</span>

7. 81 > 54，81 - 54 = 27 → 新数对：(54, 27)；

8. 54 > 27，54 - 27 = 27 → 新数对：(27, 27)；

9. 数对相等，最大公约数为<span style="color:#9221ff">27</span>。
   
   ### **三、代码实现**：
   
   ```c
   int gcd_subtraction(int a, int b) {
       // 先处理偶数优化
       int count = 0; // 记录除以2的次数
   
       while (a % 2 == 0 && b % 2 == 0) {
           a /= 2;
           b /= 2;
           count++;
       }
       // 核心减法循环
       while (a != b) {
           if (a > b)
           {
               a -= b;
           }
           else {
               b -= a;
           }
       }
       // 还原之前除以的2的幂次
       return a * (1 << count); // 1 << count 等价于 2^count
   }
   ```
   
   <span style="color:#32833a">**备注**：基础版更相减损术时间复杂度为O(max(a, b))，相比辗转相除法效率更低；加入偶数优化后，时间复杂度可降低至O(log max(a, b))，但实际应用中仍以辗转相除法为主。更相减损术体现了中国古代数学的智慧，是数论中重要的经典算法。</span>
