# 二维数组旋转问题（相对坐标核心）：思路、解法与知识点总结

## 一、核心背景与问题定义

### 1. 问题特征

给定一个 `n × n` 的 <font color="#209fff">二维数组</font>，要求对其中以某个点 <font color="#209fff">(cx, cy)</font> 为中心、边长为 <font color="#209fff">2r+1</font> 的奇数阶子矩阵，执行 <font color="#209fff">顺时针</font> 或 <font color="#209fff">逆时针 90°</font> 旋转，最终输出整个数组。

### 2. 核心痛点

若直接操作原数组，新值会覆盖尚未被读取的原始数据，导致结果错误。而尝试通过<font color="#32833a">绝对坐标直接计算目标位置</font>的方法，往往仅对特定中心和半径有效，**缺乏通用性**。<font color="#ee4c2e">将绝对坐标转换为相对于旋转中心的坐标进行处理，是解决所有此类问题的通用核心</font>。

## 二、核心思路：相对坐标五步法

**解决此问题的通用逻辑框架如下，适用于所有旋转场景：**

1. **定边界**：确定待旋转子矩阵在原数组中的绝对坐标范围。
2. **转相对坐标**：将子矩阵内每个点的绝对坐标，转换为以旋转中心为原点的相对偏移量。
3. **旋转偏移量**：根据旋转方向（顺时针/逆时针），按照数学规则修改相对偏移量。
4. **转回绝对坐标**：将旋转后的新偏移量，映射回原数组的绝对坐标。
5. **赋值操作**：通过一个临时数组中转，将值赋回到原数组的正确位置，避免覆盖。

### 分步详解

#### 步骤1：定边界

* **旋转中心**：<font color="#209fff">(cx, cy)</font>
* **旋转半径**：<font color="#209fff">r</font>
* **子矩阵边长**：<font color="#209fff">len = 2r + 1</font>
* **计算边界**：
  * 顶行 <font color="#209fff">top = cx - r</font>
  * 底行 <font color="#209fff">bottom = cx + r</font>
  * 左列 <font color="#209fff">left = cy - r</font>
  * 右列 <font color="#209fff">right = cy + r</font>
* <font color="#32833a">备注</font>：通常题目保证输入合法，边界不会超出数组范围。若需处理，在此步骤进行判断。

#### 步骤2：转相对坐标（**核心第一步**）

对于子矩阵内任意一点，其绝对坐标为 <font color="#209fff">(i, j)</font>。计算它相对于旋转中心的偏移：

* 行偏移：<font color="#209fff">dx = i - cx</font> （中心上方为负，下方为正）
* 列偏移：<font color="#209fff">dy = j - cy</font> （中心左侧为负，右侧为正）

<font color="#9221ff">举例</font>：中心为 <font color="#209fff">(2, 2)</font>。

* 点 <font color="#209fff">(1, 1)</font> → `dx = -1`, `dy = -1`
* 点 <font color="#209fff">(3, 2)</font> → `dx = 1`, `dy = 0`

#### 步骤3：旋转偏移量（**核心第二步**）

旋转操作的本质是改变这个相对偏移 `(dx, dy)`。90°旋转的数学规则是固定的：

| 旋转方向        | 相对偏移变换规则                       | 记忆口诀        |
|:----------- |:------------------------------ |:----------- |
| **顺时针 90°** | `(dx_new, dy_new) = (dy, -dx)` | **行变列，列取反** |
| **逆时针 90°** | `(dx_new, dy_new) = (-dy, dx)` | **行取反，列变行** |

<font color="#9221ff">举例</font>：接上例，点 `(1, 1)` 的相对偏移为 `(-1, -1)`。

* 顺时针旋转 → 新偏移为 `(-1, 1)` （`dx_new = -1`, `dy_new = 1`）
* 逆时针旋转 → 新偏移为 `(1, -1)` （`dx_new = 1`, `dy_new = -1`）

#### 步骤4：转回绝对坐标（**核心第三步**）

得到新偏移 `(dx_new, dy_new)` 后，计算该点旋转后应处的绝对坐标：

* 新行号：<font color="#209fff">ni = cx + dx_new</font>
* 新列号：<font color="#209fff">nj = cy + dy_new</font>

<font color="#9221ff">举例</font>：中心为 `(2, 2)`，顺时针旋转后的新偏移为 `(-1, 1)`。

* `ni = 2 + (-1) = 1`
* `nj = 2 + 1 = 3`
* 即点 `(1, 1)` 顺时针旋转 90° 后，将移动到 `(1, 3)`。

#### 步骤5：赋值操作（**避坑关键**）

**必须使用临时数组**。直接赋值会覆盖未处理的数据。正确流程是：

1. 将原子矩阵的数据复制到一个大小相同的**临时数组**中。
2. 遍历**临时数组**中的每一个位置 `(i, j)`。
3. 对每个点，通过上述`步骤2-4`计算它在**原数组**中旋转后的目标位置 `(ni, nj)`。
4. 将**临时数组**中 `(i, j)` 的值，赋给**原数组**的 `(ni, nj)` 位置。

**逻辑链**：原数组`[i][j]` → 临时数组`[i][j]` → (计算旋转) → 赋值到原数组`[ni][nj]`

## 三、典型错误与避坑指南

### 1. 绝对坐标硬凑法（高频错误）

* **错误做法**：试图直接用 `cx + r - j + 1` 等复杂表达式，直接计算目标绝对坐标。
* **后果**：该表达式通常是为特定中心 `(cx, cy)` 和半径 `r` “凑”出来的，一旦中心或半径改变，公式立即失效，结果错误。
* <font color="#32833a">批注</font>：<font color="#ee4c2e">相对坐标法是通用解</font>，绝对坐标硬凑法仅是特定情况下的“巧合正确”，不可取。

### 2. 未使用临时数组

* **错误做法**：直接在原数组上计算并赋值。
* **后果**：先被修改位置的数据，覆盖了后续还需读取的原始数据，导致旋转结果混乱、数据重复或丢失。

### 3. 相对坐标原点选错

* **错误做法**：错误地将子矩阵的左上角 `(top, left)` 当作相对坐标系的原点。
* **后果**：旋转后，整个子矩阵会发生平移，中心点位置发生偏移，结果完全错误。

## 五、通用解法代码模板（步骤化）

```python
# 假设原始数组为 matrix, 操作参数为 (cx, cy, r, z)，其中 z=0 表示顺时针，z=1 表示逆时针。
def rotate_submatrix(matrix, cx, cy, r, z):
    n = len(matrix)
    # 1. 定边界
    top, bottom = cx - r, cx + r
    left, right = cy - r, cy + r

    # 2. 创建临时数组，复制原子矩阵数据
    length = 2 * r + 1
    temp = [[0] * length for _ in range(length)]
    for i in range(top, bottom + 1):
        for j in range(left, right + 1):
            temp[i - top][j - left] = matrix[i][j]

    # 3. 遍历临时数组，计算旋转并赋值回原数组
    for i in range(length):
        for j in range(length):
            # 3.1 转相对坐标 (相对于中心cx, cy)
            dx = (top + i) - cx  # 等价于 i_in_original - cx
            dy = (left + j) - cy # 等价于 j_in_original - cy

            # 3.2 旋转偏移量
            if z == 0:  # 顺时针
                dx_new, dy_new = dy, -dx
            else:       # 逆时针
                dx_new, dy_new = -dy, dx

            # 3.3 转回绝对坐标
            ni = cx + dx_new
            nj = cy + dy_new

            # 3.4 赋值（数据来自临时数组）
            matrix[ni][nj] = temp[i][j]

    return matrix
```

## 六、总结

二维数组子矩阵旋转问题的核心是掌握 <font color="#ee4c2e">“相对坐标的数学映射”</font>。

**牢记五步法**：定边界 → 转相对坐标 → 旋转偏移 → 转回绝对坐标 → 临时数组赋值。这套逻辑能通用地解决所有以任意点为中心、任意奇数边长的子矩阵旋转问题。

**摒弃错误方法**：绝对坐标硬凑法只是针对个别情况的“特解”，而非“通解”，一旦参数变化就会失效。

**理解本质**：**旋转操作的本质是相对偏移量的变换，而不是绝对坐标的拼凑**。抓住这个本质，此类问题便可迎刃而解。
