公式 `位数 = ⌊log₁₀N⌋ + 1` 是**通用规则**—— 只要 `N` 是**大于 0 的正整数**（注意：如果 N 是小数，“位数” 无数学意义），无论 N 是 2 的 x 次方、10 的 x 次方，还是任意正整数（比如 123、4567、999999），这个公式都成立。

“位数” 的本质是：找到最大的整数 `k`，使得 `10ᵏ⁻¹ ≤ N < 10ᵏ`。

对这个不等式取 10 为底的对数：

`k-1 ≤ log₁₀N < k`

因此 `⌊log₁₀N⌋ = k-1`，两边 + 1 得 `k = ⌊log₁₀N⌋ + 1`（k 就是位数）。

### 核心代码部分：

```cpp
double log_val = log10(N);    // 计算log10(N)
int digits = floor(log_val) + 1;  // 向下取整后+1
```

### 完整代码：

### 一、计算任意正整数 N 的位数（最核心基础）

```cpp
#include <iostream>
#include <cmath>  // 仅引入必需的数学库 用于log10运算

int main() {
    // 1. 输入任意正整数N
    int N;
    std::cout << "请输入正整数N：";
    std::cin >> N;

    // 2. 核心逻辑：位数 = floor(log10(N)) + 1
    double log_val = log10(N);    // 计算log10(N)
    int digits = floor(log_val) + 1;  // 向下取整后+1

    // 3. 输出结果
    std::cout << N << " 的位数是：" << digits << std::endl;

    return 0;
}
```

### 二、仅计算 2^x 的位数（最精简）

```cpp
#include <iostream>
#include <cmath>

int main() {
    // 1. 输入x（2的x次方）
    int x;
    std::cout << "请输入x（计算2^x的位数）：";
    std::cin >> x;

    // 2. 核心逻辑：利用log10(2^x) = x*log10(2)简化
    double log_val = x * log10(2);  // 替代直接计算2^x再取log10
    int digits = floor(log_val) + 1;

    // 3. 输出结果
    std::cout << "2^" << x << " 的位数是：" << digits << std::endl;

    return 0;
}
```
