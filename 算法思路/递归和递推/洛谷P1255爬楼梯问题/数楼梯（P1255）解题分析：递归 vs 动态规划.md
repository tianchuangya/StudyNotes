# 数楼梯（P1255）解题分析：递归 vs 动态规划

## 一、题目核心信息

**题目描述**：楼梯有 <font color="#209fff">N</font> 阶，上楼可以一步上一阶，也可以一步上二阶，计算共有多少种不同的走法。
**输入**：一个数字（楼梯数 <font color="#209fff">N</font>），<font color="#ee4c2e">1≤N≤5000</font>。
**输出**：走法总数。
**核心难点**：<font color="#ee4c2e">N≤5000时，走法数是上千位的超大数，普通数值类型（int/long long）会溢出，必须用高精度加法</font>。

## 二、递归解法思考过程

### 1. 核心逻辑推导

递归的本质是 <font color="#ee4c2e">自顶向下拆解问题</font>：

- 定义 <font color="#209fff">f(n)</font> 为爬 <font color="#209fff">n</font> 阶楼梯的走法数；

- 最后一步只有两种选择：走1阶（依赖 <font color="#209fff">f(n-1)</font>）、走2阶（依赖 <font color="#209fff">f(n-2)</font>）；

- 递推关系：<font color="#ee4c2e">f(n) = f(n-1) + f(n-2)</font>；

- 递归边界（最小子问题）：
  
  - <font color="#209fff">n=1</font> 时，<font color="#9221ff">f(1)=1</font>（仅1种走法：1阶）；
  
  - <font color="#209fff">n=2</font> 时，<font color="#9221ff">f(2)=2</font>（两种走法：1+1、2）。
    
    ### 2. 高精度适配思考
    
    由于 <font color="#209fff">N≤5000</font>，普通递归的数值计算会溢出，需将「数值相加」替换为「高精度数组相加」：

- 用 <font color="#209fff">vector<int></font> 逆序存储大数（如 123 存为 <font color="#9221ff">[3,2,1]</font>），方便低位到高位相加；

- 递归过程中，每次计算 <font color="#209fff">f(n)</font> 时，调用高精度加法函数合并 <font color="#209fff">f(n-1)</font> 和 <font color="#209fff">f(n-2)</font> 的结果。
  
  ### 3. 注意点

- <font color="#ee4c2e">递归深度问题</font>：N=5000时，普通递归会触发栈溢出，需用「记忆化递归」缓存已计算结果，避免重复计算；

- <font color="#ee4c2e">高精度数组操作</font>：加法需处理进位，逆序存储的数组最终要正序输出；

- <font color="#32833a">备注</font>：递归仅适合理解逻辑，实际提交会因栈溢出/超时风险更高，动态规划是更优选择。
  
  ### 4. 完整代码（记忆化递归+高精度）
  
  ```cpp
  #include <iostream>
  #include <vector>
  #include <algorithm>
  using namespace std;
  // 高精度加法：a + b（逆序存储），返回结果
  vector<int> add(vector<int>& a, vector<int>& b) {
  if (a.size() < b.size()) return add(b, a);
  int carry = 0; // 进位
  vector<int> res;
  for (int i = 0; i < a.size() || carry; ++i) {
  int x = i < a.size() ? a[i] : 0;
  int y = i < b.size() ? b[i] : 0;
  int sum = x + y + carry;
  res.push_back(sum % 10);
  carry = sum / 10;
  }
  return res;
  }
  // 记忆化缓存：memo[n] 存储 f(n) 的高精度结果（逆序）
  vector<vector<int>> memo;
  // 递归计算 f(n)
  vector<int> dfs(int n) {
  // 递归边界
  if (n == 1) return {1};
  if (n == 2) return {2};
  // 缓存命中，直接返回
  if (!memo[n].empty()) return memo[n];
  // 递归拆解：f(n) = f(n-1) + f(n-2)
  vector<int> fn_1 = dfs(n-1);
  vector<int> fn_2 = dfs(n-2);
  vector<int> fn = add(fn_1, fn_2);
  // 存入缓存
  memo[n] = fn;
  return fn;
  }
  int main() {
  int n;
  cin >> n;
  // 初始化缓存，大小 n+1（下标对应楼梯数）
  memo.resize(n+1);
  // 调用递归
  vector<int> ans = dfs(n);
  // 逆序输出（恢复正序）
  for (int i = ans.size() - 1; i >= 0; --i) {
  cout << ans[i];
  }
  cout << endl;
  return 0;
  }
  ```
  
  ## 三、动态规划解法思考过程
  
  ### 1. 核心逻辑推导
  
  动态规划的本质是 <font color="#ee4c2e">自底向上递推</font>：

- 状态定义：<font color="#209fff">dp[n]</font> 为爬 <font color="#209fff">n</font> 阶楼梯的走法数；

- 状态转移方程：<font color="#ee4c2e">dp[n] = dp[n-1] + dp[n-2]</font>（与递归递推关系一致）；

- 初始状态（递推起点）：
  
  - <font color="#209fff">dp[1] = 1</font>；
  - <font color="#209fff">dp[2] = 2</font>；

- 递推方向：从 <font color="#209fff">3</font> 到 <font color="#209fff">n</font>，逐步计算每个 <font color="#209fff">dp[i]</font>，避免递归的重复计算和栈溢出。
  
  ### 2. 高精度适配思考

- 用 <font color="#209fff">vector<int></font> 替代普通变量存储 <font color="#209fff">dp[i]</font>，逆序存储大数；

- 用「滚动数组」优化空间：仅保留 <font color="#209fff">dp[i-1]</font> 和 <font color="#209fff">dp[i-2]</font> 的结果，无需存储完整的 <font color="#209fff">dp</font> 数组（空间复杂度从 O(n) 降为 O(1)）。
  
  ### 3. 注意点

- <font color="#ee4c2e">边界条件处理</font>：必须单独处理 <font color="#209fff">n=1</font> 和 <font color="#209fff">n=2</font>，避免空数组遍历错误；

- <font color="#ee4c2e">高精度加法细节</font>：进位需处理到底（如 999+1=1000 的最高位进位）；

- <font color="#ee4c2e">输出格式</font>：逆序存储的数组需正序输出，且末尾加换行符适配评测格式；

- <font color="#32833a">备注</font>：动态规划是本题的最优解，时间复杂度 O(n×len)（len 为大数位数），空间复杂度 O(len)，适配 N=5000 的极限数据。
  
  ### 4. 完整代码（动态规划+高精度+空间优化）
  
  ```cpp
  #include <iostream>
  #include <vector>
  using namespace std;
  // 高精度加法：a + b（逆序存储），返回结果
  vector<int> add(vector<int>& a, vector<int>& b) {
  if (a.size() < b.size()) return add(b, a);
  int carry = 0; // 进位
  vector<int> res;
  for (int i = 0; i < a.size() || carry; ++i) {
  int x = i < a.size() ? a[i] : 0;
  int y = i < b.size() ? b[i] : 0;
  int sum = x + y + carry;
  res.push_back(sum % 10); // 存储当前位
  carry = sum / 10; // 更新进位
  }
  return res;
  }
  int main() {
  int n;
  cin >> n;
  // 边界条件：单独处理n=1/n=2，避免空数组
  if (n == 1) {
  cout << 1 << endl;
  return 0;
  }
  if (n == 2) {
  cout << 2 << endl;
  return 0;
  }
  // 滚动数组优化：仅保留前两个状态
  vector<int> dp_1 = {1}; // dp[i-2]，初始为dp[1]
  vector<int> dp_2 = {2}; // dp[i-1]，初始为dp[2]
  vector<int> dp; // dp[i]
  // 自底向上递推：从3到n
  for (int i = 3; i <= n; ++i) {
  dp = add(dp_1, dp_2); // dp[i] = dp[i-1] + dp[i-2]
  dp_1 = dp_2; // 前移：dp[i-2] = 原dp[i-1]
  dp_2 = dp; // 前移：dp[i-1] = 现dp[i]
  }
  // 逆序遍历输出（恢复正序）
  for (int i = dp.size() - 1; i >= 0; --i) {
  cout << dp[i];
  }
  cout << endl; // 补充换行，适配评测格式
  return 0;
  }
  ```
  
  ## 四、递归 vs 动态规划 对比总结
  
  | 维度    | 递归（记忆化）            | 动态规划（滚动数组）        |
  | ----- | ------------------ | ----------------- |
  | 核心思路  | 自顶向下拆解             | 自底向上递推            |
  | 时间复杂度 | O(n×len)（缓存避免重复计算） | O(n×len)（最优）      |
  | 空间复杂度 | O(n×len)（缓存数组）     | O(len)（仅存两个大数）    |
  | 稳定性   | 易栈溢出（N=5000时风险高）   | 无栈溢出，适配所有N        |
  | 适用场景  | 理解逻辑、小范围N（N≤1000）  | 实际提交、全范围N（N≤5000） |
  | 核心优势  | 逻辑直观，贴合问题拆解思路      | 效率最高，空间最优         |
