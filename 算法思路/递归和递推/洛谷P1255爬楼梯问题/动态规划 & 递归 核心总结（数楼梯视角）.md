# 动态规划 & 递归 核心总结（数楼梯视角洛谷P1255）

## 一、基本概念（黑体标注核心，色彩区分维度）

### 1. 递归

<span style="color:#ee4c2e; font-weight:bold">核心定义</span>：函数**自己调用自己**，将<span style="color:#209fff">大问题</span>拆解为<span style="color:#209fff">和原问题相似但规模更小</span>的子问题，直到触达<span style="color:#ee4c2e">递归边界</span>（可直接回答的最小子问题），再从边界往回推导结果。
<span style="color:#32833a">备注</span>：本质是「自顶向下」的问题拆解，依赖系统栈完成“拆问题+回算结果”。

### 2. 动态规划（DP）

<span style="color:#ee4c2e; font-weight:bold">核心定义</span>：将<span style="color:#209fff">大问题</span>拆解为<span style="color:#209fff">重叠子问题</span>，先求解<span style="color:#ee4c2e">初始状态</span>（最小子问题），再通过<span style="color:#ee4c2e">状态转移方程</span>「自底向上」递推求解更大的问题，最终得到目标结果。
<span style="color:#32833a">备注</span>：核心是“缓存子问题结果，避免重复计算”，用循环替代递归栈，无栈溢出风险。

### 1. 递归做题思路

| 步骤                                                                                                                                  | 核心动作                       | 数楼梯案例落地                                          |
| ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ------------------------------------------------ |
| 1. 定义函数                                                                                                                             | 明确函数的“输入（问题规模）”和“输出（问题答案）” | 定义`dfs(n)`：输入楼梯数`n`，输出`n`阶的走法数（高精度数组）            |
| 2. 找递归边界                                                                                                                            | 确定“能直接回答”的最小子问题            | `n=1`返回`{1}`，`n=2`返回`{2}`                        |
| 3. 找递推关系                                                                                                                            | 把大问题拆成更小的子问题               | `dfs(n) = add(dfs(n-1), dfs(n-2))`（高精度加法合并子问题结果） |
| 4. 优化（可选）                                                                                                                           | 加记忆化缓存，避免重复计算              | 用`memo[n]`存储`dfs(n)`的结果，命中缓存直接返回                 |
| <span style="color:#9221ff">举例</span>：计算`dfs(4)` → 拆为`dfs(3)+dfs(2)` → `dfs(3)`拆为`dfs(2)+dfs(1)` → 触达边界后回算：`dfs(3)=3` → `dfs(4)=5`。 |                            |                                                  |

### 2. 动态规划做题思路

| 步骤                                                                                                 | 核心动作                | 数楼梯案例落地                              |
| -------------------------------------------------------------------------------------------------- | ------------------- | ------------------------------------ |
| 1. 状态定义                                                                                            | 明确`dp[i]`的含义（子问题答案） | `dp[i]`：`i`阶楼梯的走法数（高精度数组）            |
| 2. 初始状态                                                                                            | 确定最小子问题的答案          | `dp[1]={1}`，`dp[2]={2}`              |
| 3. 状态转移方程                                                                                          | 子问题之间的计算关系          | `dp[i] = add(dp[i-1], dp[i-2])`      |
| 4. 递推求解                                                                                            | 从初始状态推到目标状态         | 从`i=3`循环到`n`，逐次计算`dp[i]`             |
| 5. 空间优化（可选）                                                                                        | 用滚动变量替代完整数组         | 仅保留`dp[i-1]`和`dp[i-2]`，无需存储所有`dp[i]` |
| <span style="color:#9221ff">举例</span>：计算`dp[4]` → 先算`dp[1]=1`、`dp[2]=2` → 算`dp[3]=3` → 算`dp[4]=5`。 |                     |                                      |

## 三、注意点（按优先级标注重点）

### 1. 递归注意点

- <span style="color:#ee4c2e; font-weight:bold">递归边界必须完整</span>：遗漏边界会导致无限递归（栈溢出），如数楼梯漏了`n=1`会一直调用`dfs(0)`、`dfs(-1)`；
- <span style="color:#ee4c2e; font-weight:bold">普通递归必加记忆化</span>：无记忆化时时间复杂度呈指数级（如数楼梯`O(2ⁿ)`），n≥30即超时；
- <span style="color:#ee4c2e; font-weight:bold">大数场景适配高精度</span>：数楼梯`n≤5000`时，需用数组存储结果，不能用`int/long long`；
- <span style="color:#32833a">备注</span>：递归深度有限制（如C++默认栈深度约1e4），`n=5000`时纯递归会栈溢出，仅适合理解逻辑。
  
  ### 2. 动态规划注意点
- <span style="color:#ee4c2e; font-weight:bold">状态定义要精准</span>：`dp[i]`的含义直接决定转移方程是否正确，如数楼梯不能把`dp[i]`定义为“走到`i`阶的步数”；
- <span style="color:#ee4c2e; font-weight:bold">初始状态要贴合场景</span>：数楼梯`dp[1]=1`、`dp[2]=2`是场景决定的，而非数学斐波那契的`dp[1]=1`、`dp[2]=1`；
- <span style="color:#ee4c2e; font-weight:bold">边界条件单独处理</span>：数楼梯`n=1/n=2`时循环不执行，需直接输出结果，避免空数组遍历错误；
- <span style="color:#ee4c2e; font-weight:bold">高精度加法处理进位</span>：相加时要处理到“无进位”，如数楼梯`999+1=1000`需保留最高位的1；
- <span style="color:#32833a">备注</span>：动态规划是数楼梯的最优解，空间优化后仅需存储两个高精度数组，适配`n=5000`的极限数据。
  
  ## 四、核心总结（对比+本质）
  
  ### 1. 核心对比表
  
  | 维度    | 递归（记忆化）        | 动态规划（自底向上）      |
  | ----- | -------------- | --------------- |
  | 执行方向  | 自顶向下（拆大→小）     | 自底向上（推小→大）      |
  | 核心逻辑  | 依赖系统栈拆解+回算     | 依赖循环递推+缓存       |
  | 时间复杂度 | O(n×len)（记忆化后） | O(n×len)（最优）    |
  | 空间复杂度 | O(n×len)（缓存+栈） | O(len)（滚动数组优化后） |
  | 稳定性   | 易栈溢出（n大时）      | 无栈溢出，适配所有n      |
  | 适用场景  | 理解问题逻辑、小范围n    | 实际提交、大范围n       |
  
  ### 2. 本质结论
- <span style="color:#ee4c2e; font-weight:bold">并非“相反”，而是“方向相反的同逻辑”</span>：递归和DP的核心递推关系（如数楼梯`f(n)=f(n-1)+f(n-2)`）完全一致，仅执行顺序相反；
- <span style="color:#ee4c2e; font-weight:bold">递归是“先拆后算”，DP是“先算后推”</span>：递归从目标拆到边界，再回算；DP从边界推到目标，一步到位；
- <span style="color:#ee4c2e; font-weight:bold">工程落地优先选DP</span>：DP无栈溢出、无重复计算、空间可优化，是递推类问题（如数楼梯、斐波那契）的“标准答案”；递归仅适合初期理解问题拆解逻辑。
  
  ### 3. 通用解题口诀
- 递归：<span style="color:#209fff">定函数→找边界→拆子问题→加缓存</span>；
- DP：<span style="color:#209fff">定状态→找初始→写转移→递推算</span>。
