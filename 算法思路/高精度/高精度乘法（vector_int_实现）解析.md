```cpp
#include <vector>
std::vector<int> mul(std::vector<int> a, std::vector<int> b) {
    // 步骤1：处理其中一个数为0的情况
    if ((a.size() == 1 && a[0] == 0) || (b.size() == 1 && b[0] == 0)) {
        return std::vector<int>{0};
    }

    // 步骤2：初始化结果数组
    std::vector<int> res(a.size() + b.size(), 0);

    // 步骤3：计算位积累加
```

### 步骤2：初始化结果数组

#### 代码逻辑


#### 功能说明

- 数学依据：两个数相乘的 **最大位数** = 两数位数之和（例：2位数字 `99` × 2位数字 `99` = 4位数字 `9801`）。

- 初始化：创建长度为 `a.size() + b.size()` 的向量，所有元素置 `0`，预留足够存储空间。

#### 示例

- 输入 `a = [3, 2, 1]`（3位）、`b = [5, 4]`（2位），初始化 `res` 为 `[0, 0, 0, 0, 0]`（3+2=5位）。

### 步骤3：逐位相乘并累加到位

#### 代码逻辑

```cp

    for (int j = 0; j < b.size(); j++) {
        res[i + j] += a[i] * b[j];
    }
}
```

#### 核心原理

- 位数叠加规则：`a[i]` 对应原数的 `10^i` 位（例：`a[0]` 是个位，权重 `10^0`），`b[j]` 对应原数的 `10^j` 位，相乘后权重为 `10^(i+j)`，对应结果向量的 `i+j` 下标。

- 操作：遍历 `a` 和 `b` 的每一位，将乘积累加到 `res[i+j]` 中（暂不处理进位，仅记录累加值）。

#### 示例

输入 `a = [3, 2, 1]`（123）、`b = [5, 4]`（45）：

| i（a的位） | j（b的位） | a[i]×b[j] | 累加位置 i+j | res 变化后的值   |
| ------ | ------ | --------- | -------- | ----------- |
| 0（3）   | 0（5）   | 15        | 0        | res[0] = 15 |
| 0（3）   | 1（4）   | 12        | 1        | res[1] = 12 |
| 1（2）   | 0（5）   | 10        | 1        | res[1] = 22 |
| 1（2）   | 1（4）   | 8         | 2        | res[2] = 8  |
| 2（1）   | 0（5）   | 5         | 2        | res[2] = 13 |
| 2（1）   | 1（4）   | 4         | 3        | res[3] = 4  |

### 步骤4：统一处理进位

#### 代码逻辑

```cpp
int carry = 0;
for (int k = 0; k < res.size(); k++) {
    int total = res[k] + carry;  // 当前位值 + 上一位进位
    res[k] = total % 10;         // 保留个位作为当前位结果
    carry = total / 10;          // 十位及以上作为新进位
}
```

#### 核心原理

- 模拟竖式乘法的进位规则：从低位到高位（向量从左到右）逐位处理，将当前位总和（累加值 + 上一位进位）拆分为“个位”和“新进位”。

#### 示例

基于步骤3的 `res = [15, 22, 13, 4, 0]`，进位处理过程：

| k（当前位） | total = res[k] + carry | res[k] = total%10 | carry = total/10 |
| ------ | ---------------------- | ----------------- | ---------------- |
| 0      | 15 + 0 = 15            | 5                 | 1                |
| 1      | 22 + 1 = 23            | 3                 | 2                |
| 2      | 13 + 2 = 15            | 5                 | 1                |
| 3      | 4 + 1 = 5              | 5                 | 0                |
| 4      | 0 + 0 = 0              | 0                 | 0                |

- 处理后 `res = [5, 3, 5, 5, 0]`。

### 步骤5：去除末尾前导零

#### 代码逻辑

```cpp
while (res.size() > 1 && res.back() == 0) res.pop_back();
```

#### 功能说明

- 结果向量的 **末尾对应原数的高位**，若末尾为 `0`，属于无效前导零（例：步骤4的 `res[4] = 0` 是高位前导零），需删除。

- 循环条件 `res.size() > 1` 确保：若结果本身为 `0`（如输入 `0×5`），仍保留一个 `0`，避免向量为空。

#### 示例

- 步骤4的 `res = [5, 3, 5, 5, 0]`，删除末尾的 `0` 后，`res = [5, 3, 5, 5]`。

### 步骤6：返回结果

- 返回处理后的向量 `res`，该向量为 **低位在前** 的乘法结果。

- 若需输出最终数字，需将向量逆序（例：`[5, 3, 5, 5]` 逆序后为 `5535`）。

## 五、使用注意事项

1. 输入要求：`a` 和 `b` 必须是 **低位在前** 的向量（需通过字符串逆序转换得到，例：`"123"` → `[3,2,1]`）。

3. 数据范围：使用 `int` 存储单个位时，需确保 `a[i] * b[j]` 不溢出（若处理超大型数字，可改用 `long long` 临时存储乘积）。
