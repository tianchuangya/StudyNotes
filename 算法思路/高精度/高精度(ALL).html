高精度运算全解析（加法/减法/乘法/除法/取模）是天创呀制作

高精度运算用于处理超出标准数据类型（如 int、long long）范围的大整数计算。由于大整数无法直接存储在常规变量中，通常采用数组或向量（vector）存储每一位数字，且遵循低位在前、高位在后的存储规则（便于从最低位开始逐位运算）。以下详细讲解高精度 +、-、*、/、% 五种运算的实现逻辑、注意事项及完整代码。

一、高精度加法（A + B）

核心逻辑：模拟手动加法，从最低位开始逐位相加，处理进位，最终合并结果。

关键注意点

  • 存储规则：A、B 均按「低位在前、高位在后」存储（如数字 123 存储为 [3,2,1]）。
  • 进位处理：每一位相加结果 = A[i] + B[i] + 进位，当前位结果取模 10，新进位取整除 10。
  • 长度对齐：当 A、B 长度不同时，短的数字高位补 0 继续运算。
  • 结果收尾：运算结束后，若仍有进位（如 999 + 1 = 1000），需将进位添加到结果末尾。
  • 前导零：无需额外处理前导零（因低位在前，高位补 0 不影响结果）。

实现代码

std::vector<int> add(std::vector<int> a, std::vector<int> b) {
    std::vector<int> res;
    int carry = 0;
    for (int i = 0; i < a.size() || i < b.size() || carry; i++) {
        int x = i < a.size() ? a[i] : 0;
        int y = i < b.size() ? b[i] : 0;
        int sum = x + y + carry;
        res.push_back(sum % 10);
        carry = sum / 10;
    }
    return res;
}

二、高精度减法（A - B）

核心逻辑：模拟手动减法，从最低位开始逐位相减，处理借位，最终合并结果（需保证 A ≥ B，若需支持负数需额外处理符号）。

关键注意点

  • 前提条件：默认 A ≥ B（若需处理 A < B，需先交换 A、B，结果前加负号）。
  • 借位处理：若当前位 A[i] < B[i]，则向高位借 1（A[i] += 10），并标记借位（下一位运算时 A[i+1] -= 1）。
  • 长度对齐：短数字高位补 0，确保每一位都能对应相减。
  • 结果收尾：去除结果末尾的前导零（如 1000 - 999 = 1，存储为 [1,0,0,0]，需处理为 [1]）。
  • 特殊情况：若 A == B，结果为 [0]（避免返回空向量）。
⚠️ 重要提醒：使用前需先判断 A 是否大于等于 B。可通过「比较函数」实现：若 A 长度大于 B 则 A 大；若长度相等，从高位到低位逐位比较，首个不同位数字大的则整体大。

实现代码（含比较函数）

// 比较函数：判断 a 是否大于等于 b
bool cmp(std::vector<int> a, std::vector<int> b) {
    if (a.size() != b.size()) return a.size() > b.size();
    for (int i = a.size() - 1; i >= 0; i--) {
        if (a[i] != b[i]) return a[i] > b[i];
    }
    return true; // a == b
}

// 减法函数：a - b（确保 a >= b）
std::vector<int> sub(std::vector<int> a, std::vector<int> b) {
    std::vector<int> res;
    int borrow = 0;
    for (int i = 0; i < a.size(); i++) {
        int x = a[i] - borrow;
        int y = i < b.size() ? b[i] : 0;
        if (x < y) {
            x += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }
        res.push_back(x - y);
    }
    // 去除末尾前导零
    while (res.size() > 1 && res.back() == 0) res.pop_back();
    return res;
}

三、高精度乘法（A × B）

核心逻辑：模拟手动乘法，用 A 的每一位分别与 B 的每一位相乘，结果按位累加，最后处理进位。

关键注意点

  • 结果长度：两个长度分别为 n、m 的数字相乘，结果长度最多为 n + m（如 999 × 999 = 998001，长度 3 + 3 = 6）。
  • 位积位置：A[i] × B[j] 的结果应累加到结果的第 i + j 位（如 A 的个位（i=0）× B 的十位（j=1），结果在十位（i+j=1））。
  • 进位处理：先计算所有位积的累加结果，再统一处理进位（每一位结果 = 当前值 % 10，进位 = 当前值 / 10，传递到下一位）。
  • 前导零：结果末尾可能存在前导零（如 100 × 200 = 20000，存储为 [0,0,0,0,2]），需去除。
  • 特殊情况：若 A 或 B 为 0，直接返回 [0]（避免多余运算）。
💡 优化技巧：初始化结果向量时，可直接分配 n + m 个元素（初始值为 0），避免动态扩容，提高效率。

实现代码

std::vector<int> mul(std::vector<int> a, std::vector<int> b) {
    // 处理其中一个数为0的情况
    if ((a.size() == 1 && a[0] == 0) || (b.size() == 1 && b[0] == 0)) {
        return std::vector<int>{0};
    }

    std::vector<int> res(a.size() + b.size(), 0);
    // 计算位积累加
    for (int i = 0; i < a.size(); i++) {
        for (int j = 0; j < b.size(); j++) {
            res[i + j] += a[i] * b[j];
        }
    }
    // 处理进位
    int carry = 0;
    for (int k = 0; k < res.size(); k++) {
        int total = res[k] + carry;
        res[k] = total % 10;
        carry = total / 10;
    }
    // 去除末尾前导零
    while (res.size() > 1 && res.back() == 0) res.pop_back();
    return res;
}

四、高精度除法（A ÷ B）

核心逻辑：模拟手动除法（商为高精度，除数为低精度，若需除数为高精度需额外实现），从高位到低位逐位计算商，处理余数。

关键注意点

  • 除数限制：以下实现为「高精度 ÷ 低精度」（B 为 int 类型，范围 ≤ 1e9），若需「高精度 ÷ 高精度」，需先实现「高精度减法」和「比较函数」，通过减法模拟除法（效率较低）。
  • 运算方向：与加减乘不同，除法需从高位到低位运算（因高位决定商的高位）。
  • 余数处理：每一步计算后，余数 = 余数 × 10 + 当前位数字，商的当前位 = 余数 ÷ B，余数更新为 余数 % B。
  • 商的存储：商按「高位在前、低位在后」存储（便于逐位计算），最后需反转转为「低位在前」格式（与其他运算统一）。
  • 前导零：商的高位可能存在前导零（如 100 ÷ 2 = 50，计算时先得 0、5、0，需去除高位零）。
  • 特殊情况：B 不能为 0（需提前判断）；若 A < B，商为 [0]，余数为 A。
⚠️ 重要提醒：若需支持「高精度 ÷ 高精度」，可通过「试商法」实现：每次用被除数的前 k 位与除数比较，确定商的当前位，再用被除数减去「除数 × 商的当前位」，重复此过程直到被除数小于除数。

实现代码（高精度 ÷ 低精度，返回商和余数）

// 返回 pair：first 为商（低位在前），second 为余数
std::pair<std::vector<int>, int> div_low(std::vector<int> a, int b) {
    std::vector<int> quotient;
    int remainder = 0;
    
    if (b == 0) throw "除数不能为 0"; // 异常处理
    if (a.size() == 1 && a[0] < b) {
         return std::make_pair(std::vector<int>{0}, a[0]);
    }

    // 从高位到低位运算
    for (int i = a.size() - 1; i >= 0; i--) {
        remainder = remainder * 10 + a[i];
        quotient.push_back(remainder / b);
        remainder %= b;
    }
    
    // 反转商，转为低位在前格式
    std::reverse(quotient.begin(), quotient.end());
    
    // 去除末尾前导零
    while (quotient.size() > 1 && quotient.back() == 0) quotient.pop_back();
    
    return std::make_pair(quotient, remainder);
}

五、高精度取模（A % B）

核心逻辑：取模运算的结果是除法运算的余数。因此，高精度取模可以直接利用高精度除法的逻辑来实现。

关键注意点

  • 依赖除法：高精度取模的结果等于高精度除法运算后得到的余数。
  • 运算效率：如果只需要取模结果，不必完整计算出商，可以在除法过程中仅跟踪余数，这样效率更高。
  • 特殊情况：
    • 如果 B 为 0，运算无意义（需提前判断）。
    • 如果 A 为 0，结果为 0。
    • 如果 A < B，结果为 A。
    • 结果的符号通常与被除数 A 一致（对于正数运算，结果恒为正）。

实现代码（高精度 % 低精度）

// 高精度 a 对低精度 b 取模
int mod_low(std::vector<int> a, int b) {
    int remainder = 0;
    
    if (b == 0) throw "模数不能为 0";
    if (b == 1) return 0; // 任何数模1都为0

    // 从高位到低位计算余数
    for (int i = a.size() - 1; i >= 0; i--) {
        remainder = (remainder * 10 + a[i]) % b;
        // 可以在这里加一个小优化，如果余数为0且不是最后一位，可以提前break吗？不行，因为高位可能还有数字。
        // 例如 1000 % 8, 过程是 1%8=1, 10%8=2, 20%8=4, 40%8=0。必须算完。
    }
    
    return remainder;
}

// 如果已经有了除法函数，取模可以更简单
int mod_using_div(std::vector<int> a, int b) {
    return div_low(a, b).second;
}

六、五种高精度运算的异同点总结

运算类型 核心操作 运算方向 进位/借位处理 结果长度特点 特殊处理 复杂度
加法 (+) 逐位相加 低位 → 高位 进位（carry）：sum % 10 为当前位，sum / 10 为新进位。 ≤ max(n,m) + 1 无 O(n)
减法 (-) 逐位相减 低位 → 高位 借位（borrow）：不够减时向上借位（+10）。 ≤ max(n,m) 需比较大小确保 A ≥ B；结果需去前导零。 O(n)
乘法 (*) 位积累加 + 统一进位 低位 → 高位 (两层循环) 先累加所有位积，再统一处理进位。 ≤ n + m 结果需去前导零；处理任一数为0的情况。 O(n*m)
除法 (/) 逐位求商 + 余数迭代 高位 → 低位 无进位/借位，有余数（remainder）迭代：remainder = remainder * 10 + 当前位。 ≤ max(n,m) 需处理除数为0；商需反转并去前导零；返回商和余数。 O(n) (低精度除数)
取模 (%) 迭代求余 高位 → 低位 无进位/借位，仅余数迭代：remainder = (remainder * 10 + 当前位) % mod。 - (结果为单个整数) 需处理模数为0；结果恒为非负（对正数）。 O(n) (低精度模数)

七、通用注意事项与编程建议

通用注意事项与编程建议

  • 数据存储：坚持使用「低位在前，高位在后」的存储方式，这是所有高精度运算统一的基础，能避免大量不必要的反转操作。
  • 输入输出：
    • 输入：从字符串读取大整数，然后将字符转换为数字，逆序存入向量。例如，"1234" → `[4, 3, 2, 1]`。
    • 输出：将向量逆序遍历并打印每个元素。
  • 前导零：减法和乘法的结果经常需要去除前导零（即向量末尾的零），这是保证结果正确性和整洁性的重要步骤。
  • 边界情况：务必处理好如数字为0、除数/模数为0、结果为0等边界情况，这些是程序健壮性的关键。
  • 代码复用：
    • 减法依赖于比较函数 cmp。
    • 高精度除法和取模都依赖于减法（对于高精度除数/模数）。
    • 取模可以直接复用除法的结果。
    设计函数时应考虑模块化，便于复用。
  • 性能考量：
    • 乘法 O(n*m) 的复杂度最高，是性能瓶颈。对于超大规模数字，可研究快速傅里叶变换（FFT）等高级算法。
    • 除法的效率也较低，尤其是高精度除以高精度。
  • 异常处理：对于除法和取模运算，除数或模数为0是非法操作，应在代码中抛出异常或进行断言，防止程序崩溃。
