# 十大排序算法详解

## 1. 冒泡排序 (Bubble Sort)

**适用范围**

- 数据量小（n < 1000）
- 教学演示用途
- 对稳定性有要求

**思路**

1. 重复遍历数组

2. 比较相邻元素，如果顺序错误则交换

3. 每次遍历将最大元素"冒泡"到末尾

4. 减少遍历范围直到完全有序
   
   ![](https://i-blog.csdnimg.cn/blog_migrate/bfe2e655008710a852274f86240c6963.gif)

**函数代码**

```cpp
#include <vector>
#include <algorithm>

void bubbleSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        // 每次遍历将最大的元素移动到末尾
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        // 如果没有发生交换，说明已经有序
        if (!swapped) break;
    }
}
```

**注意点**

- 时间复杂度：最好O(n)，最坏O(n²)，平均O(n²)
- 空间复杂度：O(1)，原地排序
- 稳定排序
- 加入`swapped`标志可提前终止

## 2. 选择排序 (Selection Sort)

**适用范围**

- 数据量小且交换成本低
- 内存空间有限
- 需要最小化交换次数

**思路**

1. 将数组分为已排序和未排序两部分

2. 每次从未排序部分找到最小元素

3. 将其与未排序部分第一个元素交换

4. 扩展已排序部分
   
   ![](https://i-blog.csdnimg.cn/blog_migrate/5d50f9a16c5bb410be12eee453d31ef2.gif)

**函数代码**

```cpp
void selectionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        // 找到未排序部分的最小元素索引
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        // 将最小元素交换到已排序部分的末尾
        if (minIdx != i) {
            std::swap(arr[i], arr[minIdx]);
        }
    }
}
```

**注意点**

- 时间复杂度：O(n²)，与输入数据无关
- 空间复杂度：O(1)
- 不稳定排序（可能改变相同元素的相对顺序）
- 交换次数较少（最多n-1次）

## 3. 插入排序 (Insertion Sort)

**适用范围**

- 小规模或基本有序的数据
- 在线排序（数据逐个到达）
- 链表结构排序

**思路**

1. 将数组分为已排序和未排序两部分

2. 依次将未排序元素插入到已排序部分的正确位置

3. 通过比较和移动元素找到插入位置
   
   ![](https://i-blog.csdnimg.cn/blog_migrate/7b23514289fd4c0fa3eeb9343a58baad.gif)

**函数代码**

```cpp
void insertionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];  // 待插入的元素
        int j = i - 1;

        // 将大于key的元素向后移动
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        // 插入key到正确位置
        arr[j + 1] = key;
    }
}

// 优化版本：二分查找插入位置
void insertionSortBinary(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];

        // 使用二分查找找到插入位置
        int left = 0, right = i;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (arr[mid] <= key) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        // 移动元素
        for (int j = i; j > left; j--) {
            arr[j] = arr[j - 1];
        }
        arr[left] = key;
    }
}
```

**注意点**

- 时间复杂度：最好O(n)，最坏O(n²)，平均O(n²)
- 空间复杂度：O(1)
- 稳定排序
- 对部分有序数据效率高

## 4. 希尔排序 (Shell Sort)

**适用范围**

- 中等规模数据
- 需要比O(n²)更好的性能但空间有限
- 插入排序的改进版本

**思路**

1. 将数组按增量序列分组
2. 对每组进行插入排序
3. 逐渐减小增量，最终增量为1完成排序
4. 基于插入排序，但允许远距离交换

**函数代码**

```cpp
void shellSort(std::vector<int>& arr) {
    int n = arr.size();

    // 使用Knuth序列：1, 4, 13, 40, 121, ...
    int gap = 1;
    while (gap < n / 3) {
        gap = gap * 3 + 1;
    }

    // 逐步减小gap，直到gap=1
    while (gap >= 1) {
        // 对每个子数组进行插入排序
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i;

            // 对间隔为gap的元素进行插入排序
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = temp;
        }
        gap /= 3;  // 减小间隔
    }
}
```

**注意点**

- 时间复杂度：取决于增量序列，最好O(n log n)，最坏O(n²)
- 空间复杂度：O(1)
- 不稳定排序
- 增量序列的选择影响性能

## 5. 归并排序 (Merge Sort)

**适用范围**

- 大数据量排序
- 需要稳定排序
- 链表结构排序
- 外部排序场景

**思路**

1. 分治策略：将数组递归分成两半
2. 分别对两半进行排序
3. 合并两个有序子数组
4. 自顶向下或自底向上实现

**函数代码**

```cpp
// 合并两个有序数组
void merge(std::vector<int>& arr, int left, int mid, int right) {
    int n1 = mid - left + 1;
    int n2 = right - mid;

    // 创建临时数组
    std::vector<int> L(n1), R(n2);

    // 复制数据到临时数组
    for (int i = 0; i < n1; i++)
        L[i] = arr[left + i];
    for (int j = 0; j < n2; j++)
        R[j] = arr[mid + 1 + j];

    // 合并临时数组
    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }

    // 复制剩余元素
    while (i < n1) {
        arr[k] = L[i];
        i++; k++;
    }
    while (j < n2) {
        arr[k] = R[j];
        j++; k++;
    }
}

// 递归归并排序
void mergeSort(std::vector<int>& arr, int left, int right) {
    if (left >= right) return;

    int mid = left + (right - left) / 2;

    // 递归排序左右两部分
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);

    // 合并已排序的两部分
    merge(arr, left, mid, right);
}

// 包装函数
void mergeSort(std::vector<int>& arr) {
    if (arr.empty()) return;
    mergeSort(arr, 0, arr.size() - 1);
}
```

**注意点**

- 时间复杂度：O(n log n)，稳定
- 空间复杂度：O(n)，需要额外空间
- 稳定排序
- 适用于外部排序（大数据无法全部装入内存）

## 6. 快速排序 (Quick Sort)

**适用范围**

- 通用排序，性能优异
- 内存排序（不适合外部排序）
- 对平均性能要求高

**思路**

1. 选择基准元素（pivot）
2. 分区：将小于基准的放左边，大于的放右边
3. 递归对左右子数组排序
4. 分治策略，原地排序

**函数代码**

```cpp
// 分区函数
int partition(std::vector<int>& arr, int low, int high) {
    // 选择最右元素作为基准
    int pivot = arr[high];
    int i = low - 1;  // 较小元素的边界

    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            std::swap(arr[i], arr[j]);
        }
    }

    // 将基准放到正确位置
    std::swap(arr[i + 1], arr[high]);
    return i + 1;
}

// 三数取中法选择基准（优化）
int medianOfThree(std::vector<int>& arr, int low, int high) {
    int mid = low + (high - low) / 2;

    // 对arr[low], arr[mid], arr[high]排序
    if (arr[low] > arr[mid]) std::swap(arr[low], arr[mid]);
    if (arr[low] > arr[high]) std::swap(arr[low], arr[high]);
    if (arr[mid] > arr[high]) std::swap(arr[mid], arr[high]);

    // 将中位数放到high位置作为基准
    std::swap(arr[mid], arr[high]);
    return arr[high];
}

// 优化分区函数
int partitionOptimized(std::vector<int>& arr, int low, int high) {
    // 使用三数取中法选择基准
    int pivot = medianOfThree(arr, low, high);
    int i = low - 1;
    int j = high + 1;

    while (true) {
        do {
            i++;
        } while (arr[i] < pivot);

        do {
            j--;
        } while (arr[j] > pivot);

        if (i >= j) return j;

        std::swap(arr[i], arr[j]);
    }
}

// 递归快速排序
void quickSort(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        // 分区索引
        int pi = partitionOptimized(arr, low, high);

        // 递归排序分区
        quickSort(arr, low, pi);
        quickSort(arr, pi + 1, high);
    }
}

// 包装函数
void quickSort(std::vector<int>& arr) {
    if (arr.empty()) return;
    quickSort(arr, 0, arr.size() - 1);
}
```

**注意点**

- 时间复杂度：平均O(n log n)，最坏O(n²)
- 空间复杂度：平均O(log n)，最坏O(n)（递归栈）
- 不稳定排序
- 对已排序数据可能退化为O(n²)，需要优化基准选择

## 7. 堆排序 (Heap Sort)

**适用范围**

- 需要原地排序且O(n log n)保证
- 优先级队列实现
- 需要同时获取最大/最小值

**思路**

1. 构建最大堆（或最小堆）
2. 将堆顶元素（最大）与末尾交换
3. 堆大小减1，重新调整堆
4. 重复直到堆为空

**函数代码**

```cpp
// 调整堆（下沉操作）
void heapify(std::vector<int>& arr, int n, int i) {
    int largest = i;        // 初始化最大为根
    int left = 2 * i + 1;   // 左子节点
    int right = 2 * i + 2;  // 右子节点

    // 如果左子节点大于根
    if (left < n && arr[left] > arr[largest])
        largest = left;

    // 如果右子节点大于当前最大
    if (right < n && arr[right] > arr[largest])
        largest = right;

    // 如果最大不是根
    if (largest != i) {
        std::swap(arr[i], arr[largest]);

        // 递归调整受影响的子树
        heapify(arr, n, largest);
    }
}

// 堆排序主函数
void heapSort(std::vector<int>& arr) {
    int n = arr.size();

    // 构建最大堆（从最后一个非叶子节点开始）
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    // 逐个提取元素
    for (int i = n - 1; i > 0; i--) {
        // 将当前根（最大）移动到末尾
        std::swap(arr[0], arr[i]);

        // 调整剩余堆
        heapify(arr, i, 0);
    }
}
```

**注意点**

- 时间复杂度：O(n log n)，稳定
- 空间复杂度：O(1)，原地排序
- 不稳定排序
- 对缓存不友好（访问模式不连续）

## 8. 计数排序 (Counting Sort)

**适用范围**

- 整数排序，值范围小（k=O(n)）
- 非负整数或可映射到非负整数
- 需要稳定排序且值域有限

**思路**

1. 统计每个元素出现次数
2. 计算每个元素的位置（前缀和）
3. 根据统计信息将元素放到输出数组
4. 适用于小范围整数

**函数代码**

```cpp
void countingSort(std::vector<int>& arr) {
    if (arr.empty()) return;

    // 找到最大值和最小值
    int maxVal = arr[0], minVal = arr[0];
    for (int num : arr) {
        if (num > maxVal) maxVal = num;
        if (num < minVal) minVal = num;
    }

    // 计算值范围
    int range = maxVal - minVal + 1;

    // 创建计数数组并初始化为0
    std::vector<int> count(range, 0);
    std::vector<int> output(arr.size());

    // 统计每个元素的出现次数
    for (int num : arr) {
        count[num - minVal]++;
    }

    // 计算前缀和（位置信息）
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }

    // 从后向前遍历，保证稳定性
    for (int i = arr.size() - 1; i >= 0; i--) {
        int index = arr[i] - minVal;
        output[count[index] - 1] = arr[i];
        count[index]--;
    }

    // 将结果复制回原数组
    for (int i = 0; i < arr.size(); i++) {
        arr[i] = output[i];
    }
}
```

**注意点**

- 时间复杂度：O(n + k)，k为值范围
- 空间复杂度：O(n + k)
- 稳定排序（如果从后向前填充）
- 只适用于整数且值范围不大

## 9. 桶排序 (Bucket Sort)

**适用范围**

- 数据均匀分布在一定范围内
- 浮点数排序
- 需要线性时间排序

**思路**

1. 创建一定数量的桶
2. 将元素分配到对应的桶中
3. 对每个桶内的元素排序（可使用其他算法）
4. 按顺序合并所有桶

**函数代码**

```cpp
void bucketSort(std::vector<float>& arr) {
    if (arr.empty()) return;

    int n = arr.size();

    // 1. 创建n个空桶
    std::vector<std::vector<float>> buckets(n);

    // 2. 将元素分配到桶中
    for (int i = 0; i < n; i++) {
        int bucketIdx = n * arr[i];  // 假设arr[i]在[0,1)范围内
        buckets[bucketIdx].push_back(arr[i]);
    }

    // 3. 对每个桶排序（使用插入排序）
    for (int i = 0; i < n; i++) {
        if (!buckets[i].empty()) {
            // 使用插入排序对桶内元素排序
            for (int j = 1; j < buckets[i].size(); j++) {
                float key = buckets[i][j];
                int k = j - 1;
                while (k >= 0 && buckets[i][k] > key) {
                    buckets[i][k + 1] = buckets[i][k];
                    k--;
                }
                buckets[i][k + 1] = key;
            }
        }
    }

    // 4. 合并所有桶
    int index = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < buckets[i].size(); j++) {
            arr[index++] = buckets[i][j];
        }
    }
}
```

**注意点**

- 时间复杂度：平均O(n + k)，最坏O(n²)
- 空间复杂度：O(n + k)
- 稳定排序（取决于桶内排序算法）
- 需要数据均匀分布才能达到最好性能

## 10. 基数排序 (Radix Sort)

**适用范围**

- 整数或字符串排序
- 位数固定或最大位数已知
- 需要稳定排序的整数排序

**思路**

1. 从最低位到最高位（LSD）或反之（MSD）
2. 对每一位使用稳定排序（通常计数排序）
3. 按位排序，最终得到有序序列
4. 适用于多关键字的排序

**函数代码**

```cpp
// 获取数组中最大元素的位数
int getMaxDigits(std::vector<int>& arr) {
    if (arr.empty()) return 0;

    int maxVal = arr[0];
    for (int num : arr) {
        if (num > maxVal) maxVal = num;
    }

    // 计算最大值的位数
    int digits = 0;
    while (maxVal > 0) {
        digits++;
        maxVal /= 10;
    }
    return digits;
}

// 使用计数排序对特定位数排序
void countingSortByDigit(std::vector<int>& arr, int exp) {
    int n = arr.size();
    std::vector<int> output(n);
    std::vector<int> count(10, 0);  // 0-9数字

    // 统计当前位上每个数字的出现次数
    for (int i = 0; i < n; i++) {
        int digit = (arr[i] / exp) % 10;
        count[digit]++;
    }

    // 计算前缀和（位置信息）
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }

    // 从后向前遍历，保证稳定性
    for (int i = n - 1; i >= 0; i--) {
        int digit = (arr[i] / exp) % 10;
        output[count[digit] - 1] = arr[i];
        count[digit]--;
    }

    // 将结果复制回原数组
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
}

// 基数排序主函数
void radixSort(std::vector<int>& arr) {
    if (arr.empty()) return;

    // 获取最大位数
    int maxDigits = getMaxDigits(arr);

    // 从最低位到最高位进行排序
    for (int exp = 1; maxDigits > 0; exp *= 10, maxDigits--) {
        countingSortByDigit(arr, exp);
    }
}

// 字符串版本（适用于等长字符串）
void radixSortStrings(std::vector<std::string>& arr, int stringLen) {
    const int BUCKETS = 256;  // ASCII字符集

    std::vector<std::string> output(arr.size());

    // 从最后一个字符开始排序
    for (int pos = stringLen - 1; pos >= 0; pos--) {
        std::vector<int> count(BUCKETS + 1, 0);

        // 统计当前字符的出现次数
        for (const auto& str : arr) {
            count[str[pos] + 1]++;
        }

        // 计算前缀和
        for (int b = 1; b <= BUCKETS; b++) {
            count[b] += count[b - 1];
        }

        // 分配元素到输出数组
        for (const auto& str : arr) {
            output[count[str[pos]]++] = str;
        }

        // 交换数组
        arr.swap(output);
    }
}
```

**注意点**

- 时间复杂度：O(d*(n+k))，d为位数，k为基数
- 空间复杂度：O(n + k)
- 稳定排序
- 只适用于整数或固定格式数据
- 可扩展到负数（需要偏移处理）

## 总结对比

| 排序算法 | 平均时间复杂度    | 最坏时间复杂度    | 空间复杂度    | 稳定性 | 适用场景             |
| ---- | ---------- | ---------- | -------- | --- | ---------------- |
| 冒泡排序 | O(n²)      | O(n²)      | O(1)     | 稳定  | 教学、小数据           |
| 选择排序 | O(n²)      | O(n²)      | O(1)     | 不稳定 | 交换成本高            |
| 插入排序 | O(n²)      | O(n²)      | O(1)     | 稳定  | 小数据、基本有序         |
| 希尔排序 | O(n log n) | O(n²)      | O(1)     | 不稳定 | 中等规模数据           |
| 归并排序 | O(n log n) | O(n log n) | O(n)     | 稳定  | 大数据、稳定排序         |
| 快速排序 | O(n log n) | O(n²)      | O(log n) | 不稳定 | 通用排序             |
| 堆排序  | O(n log n) | O(n log n) | O(1)     | 不稳定 | 原地排序保证O(n log n) |
| 计数排序 | O(n + k)   | O(n + k)   | O(n + k) | 稳定  | 小范围整数            |
| 桶排序  | O(n + k)   | O(n²)      | O(n + k) | 稳定  | 均匀分布数据           |
| 基数排序 | O(d*(n+k)) | O(d*(n+k)) | O(n + k) | 稳定  | 整数、字符串           |

**选择建议**：

- 小数据（n < 100）：插入排序
- 通用场景：快速排序（优化版）
- 需要稳定性：归并排序
- 整数小范围：计数排序
- 原地排序保证O(n log n)：堆排序
- 外部排序：归并排序
