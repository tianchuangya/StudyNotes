1. 列表（List）

有序、可变的元素集合，支持重复元素和混合数据类型，是 Python 中最常用的数据结构之一。

核心特性

特性 说明
定义符号 [元素1, 元素2, ...]
有序性 按插入顺序排列，支持索引访问
可变性 支持增、删、改元素（不创建新列表）
重复性 允许存在重复元素
元素约束 无约束，支持任意数据类型（包括嵌套）
适用场景 有序可修改的数据集（如任务列表、记录集合）

常用操作代码示例

# 1. 定义列表
lst = [1, "a", True, [2, 3]] # 混合类型+嵌套

# 2. 访问元素（索引/切片）
print(lst[0]) # 正索引：1
print(lst[-1]) # 负索引：[2, 3]
print(lst[1:3]) # 切片：["a", True]

# 3. 增删改
lst.append(4) # 末尾添加：[1, "a", True, [2,3], 4]
lst.insert(1, "b") # 指定位置插入：[1, "b", "a", ...]
lst[0] = 100 # 修改元素：[100, "b", "a", ...]
lst.pop(2) # 按索引删除：删除 "a"
lst.remove(True) # 按值删除：删除 True

# 4. 其他常用方法
lst.extend([5, 6]) # 扩展列表：[100, "b", [2,3], 4,5,6]
lst.sort() # 排序（仅同类型元素可用）
print(lst)

2. 元组（Tuple）

有序、不可变的元素集合，支持重复元素和混合数据类型，比列表更轻量、访问速度更快。

核心特性

特性 说明
定义符号 (元素1, 元素2, ...)（单个元素需加逗号：(5,)）
有序性 按插入顺序排列，支持索引访问
可变性 不可变（无法增删改元素，嵌套可变元素内部可改）
重复性 允许存在重复元素
元素约束 无约束，支持任意数据类型（包括嵌套）
适用场景 固定数据集（如坐标、日期）、字典键、函数返回值

常用操作代码示例

# 1. 定义元组
tpl = (1, "a", True, (2, 3]) # 混合类型+嵌套
tpl_single = (5,) # 单个元素必须加逗号（否则视为普通类型）

# 2. 访问元素（索引/切片）
print(tpl[1]) # 正索引："a"
print(tpl[-2]) # 负索引：True
print(tpl[0:2]) # 切片：(1, "a")（返回新元组）

# 3. 不可变特性（以下代码会报错）
# tpl[0] = 100 # 报错：不允许修改元素
# tpl.append(4) # 报错：无 append 方法

# 4. 合法操作
tpl_new = tpl + (4, 5) # 拼接：返回新元组
tpl_repeat = tpl * 2 # 重复：元素重复2次
print(tpl.count("a")) # 统计元素次数：1
print(tpl.index(1)) # 查找元素索引：0

3. 字典（Dictionary）

键值对映射的集合（Python 3.7+ 保证插入顺序），键唯一且不可变，值可任意，查询效率极高。

核心特性

特性 说明
定义符号 {key1: value1, key2: value2, ...}
有序性 Python 3.7+ 保证插入顺序，之前版本无序
可变性 支持增、删、改键值对
重复性 键唯一（重复键会覆盖），值可重复
元素约束 键：不可变类型（int/str/tuple）；值：任意类型
适用场景 键值映射数据（如用户信息、配置参数、缓存）

常用操作代码示例

# 1. 定义字典
dct = {
"name": "Tom",
"age": 20,
"is_student": True,
"hobbies": ["reading", "sports"]
}

# 2. 访问值（键访问/get方法）
print(dct["name"]) # 直接访问："Tom"（键不存在报错）
print(dct.get("gender", "unknown")) # get方法：键不存在返回默认值

# 3. 增删改键值对
dct["gender"] = "male" # 添加键值对
dct["age"] = 21 # 修改值（键已存在）
del dct["is_student"] # 按键删除
dct.pop("hobbies") # pop删除：返回删除的值

# 4. 遍历字典
for key in dct.keys():
print(key) # 遍历所有键
for value in dct.values():
print(value) # 遍历所有值
for k, v in dct.items():
print(k, v) # 遍历键值对

4. 集合（Set）

无序、可变的元素集合，自动去重，支持高效的集合运算（交集、并集、差集）。

核心特性

特性 说明
定义符号 {元素1, 元素2, ...}（空集合：set()）
有序性 无序，无法通过索引访问
可变性 支持增、删元素
重复性 自动去重，不允许重复元素
元素约束 元素必须是不可变类型（int/str/tuple）
适用场景 去重、集合运算（如共同元素、差异元素）、高效成员判断

常用操作代码示例

# 1. 定义集合
s = {1, 2, 3, "a", (4, 5)} # 元素为不可变类型
empty_set = set() # 空集合（不能用 {}，{}是空字典）
s_dup = set([1, 2, 2, 3]) # 自动去重：{1,2,3}

# 2. 增删元素
s.add(6) # 添加单个元素
s.update([7, 8]) # 添加多个元素（可迭代对象）
s.remove(2) # 按值删除（元素不存在报错）
s.discard(9) # 按值删除（元素不存在不报错）

# 3. 集合运算（核心功能）
s1 = {1, 2, 3, 4}
s2 = {3, 4, 5, 6}
print(s1 | s2) # 并集：{1,2,3,4,5,6}
print(s1 & s2) # 交集：{3,4}
print(s1 - s2) # 差集：s1有s2没有：{1,2}
print(s1 ^ s2) # 对称差集：互不相同的元素：{1,2,5,6}

# 4. 成员判断（效率 O(1)，比列表快）
print(3 in s1) # True

6. 四大数据结构整体对比

对比维度 列表（List） 元组（Tuple） 字典（Dictionary） 集合（Set）
定义符号 [] () {key: value} {} / set()
有序性 是 是 是（3.7+） 否
可变性 是 否 是 是
元素/键约束 无约束 无约束 键：不可变类型 元素：不可变类型
重复性 允许 允许 键唯一，值允许 不允许（自动去重）

核心优势 有序可修改 轻量、安全、高效 快速键值查询 去重、集合运算
