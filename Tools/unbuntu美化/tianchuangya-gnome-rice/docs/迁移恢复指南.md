# tianchuangya Ubuntu 迁移恢复指南

目标：不用做笨重的整机 ISO，而是用“远程仓库 + 一键安装脚本 + 用户数据备份包”恢复整套 Ubuntu 桌面体验。

---

## 1. 日常维护：把当前配置导回项目

当你手动改过 GNOME 扩展、Dock、主题、输入法、终端或壁纸后，运行：

```bash
cd ~/桌面/unbuntu美化/tianchuangya-gnome-rice
bash export-current-config.sh
```

它会同步：

- GNOME Shell 主题；
- 图标、鼠标；
- 悬浮球扩展；
- 灵动岛扩展；
- Fcitx5 配置与皮肤；
- XFCE Terminal 配置；
- 微信 desktop 启动项；
- dconf/gsettings 摘要。

---

## 2. 备份用户数据

普通备份：

```bash
cd ~/桌面/unbuntu美化/tianchuangya-gnome-rice
bash backup-user-data.sh
```

加密备份：

```bash
TIANCHUANGYA_BACKUP_PASSWORD='你的强密码' bash backup-user-data.sh
```

默认输出：

```text
~/桌面/unbuntu美化/user-data-backups/
```

备份包含常见用户目录和常用配置，并排除缓存、Trash、`node_modules`、构建目录等。

---

## 3. 推送项目到远程仓库

第一次：

```bash
cd ~/桌面/unbuntu美化/tianchuangya-gnome-rice
bash sync-remote.sh https://gitee.com/你的用户名/tianchuangya-gnome-rice.git
```

之后：

```bash
bash sync-remote.sh
```

脚本会：

- 初始化 git；
- 配置 origin；
- 检查脚本语法；
- 扫描疑似 token；
- 本地 commit。

它不会自动 push。确认没问题后手动：

```bash
git push -u origin main
```

如果默认分支不是 `main`，先执行：

```bash
git branch -M main
```

---

## 4. 新电脑恢复

安装一台干净 Ubuntu 后：

```bash
sudo apt update
sudo apt install -y git curl tar zstd
mkdir -p ~/桌面/unbuntu美化
git clone https://gitee.com/你的用户名/tianchuangya-gnome-rice.git ~/桌面/unbuntu美化/tianchuangya-gnome-rice
cd ~/桌面/unbuntu美化/tianchuangya-gnome-rice
bash install.sh
bash doctor.sh
```

如果你把 `bootstrap.sh` 单独下载到新电脑，也可以：

```bash
bash bootstrap.sh https://gitee.com/你的用户名/tianchuangya-gnome-rice.git
```

---

## 5. 新电脑恢复用户数据

普通备份：

```bash
cd ~/桌面/unbuntu美化/tianchuangya-gnome-rice
bash restore-user-data.sh ~/桌面/unbuntu美化/user-data-backups/某个备份包.tar.zst
```

加密备份：

```bash
TIANCHUANGYA_BACKUP_PASSWORD='你的强密码' \
bash restore-user-data.sh ~/桌面/unbuntu美化/user-data-backups/某个备份包.tar.zst.enc
```

恢复脚本不会直接覆盖已有文件；冲突内容会先移动到：

```text
~/.local/share/tianchuangya-gnome-rice/restore-safety/
```

---

## 6. 私密信息原则

不要提交：

- `.env.local`
- `publish.conf`
- Gitee/GitHub token
- SSH 私钥
- GPG 私钥
- 用户数据备份包
- Android `local.properties`

真实 token 用 `.env.local` 或本机私有 `publish.conf` 保存。

示例：

```bash
cp .env.example .env.local
```

然后编辑 `.env.local`，填本机真实值。

---

## 7. 推荐恢复顺序

```text
1. 安装 Ubuntu
2. clone tianchuangya-gnome-rice
3. bash install.sh
4. 注销/重登
5. bash doctor.sh
6. 恢复用户数据
7. 安装手机 APK
8. 配置灵动岛同步
9. 再跑 doctor.sh
```

这样比整机 ISO 更灵活，后续更新也只需要改脚本和项目文件。
