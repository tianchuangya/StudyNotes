# 修改记录 — 2026-09-02（第二轮：材质分层重构 + Bug 修复 + 性能治理）

> 本轮改动在上一轮"零模糊纯 CSS 玻璃"的基础上，按 Apple Liquid Glass 的分层材质逻辑重构，
> 并修复悬浮球交互 Bug、治理性能问题。**需要重启 GNOME Shell（Alt+F2 → r 或注销重登）生效。**

## 1. 悬浮球 curtain-wallpaper@local v2 —— 交互重写（修复"用剪贴板后左键失效"）

根因与修复：

* 旧实现用 `global.stage` 级 captured-event 手动追踪拖拽，配合 5px 的位移阈值判定：
  触摸板点击的微小抖动超过阈值就会被判为"拖拽"而不是"点击"，点击静默失效；
  release 事件被其他输入状态（菜单抓取）吞掉时同样失联。
* 新实现与 GNOME 官方 dnd（`js/ui/dnd.js`）同机制：
  * 按下时 `global.stage.grab(ball)` 抓取，事件固定送达球的 `'event'` 信号
    （dnd 源码注释明确：抓取期间捕获阶段不会发生，必须连 `'event'` 而非 `'captured-event'`）；
  * 拖拽阈值取桌面设置 `drag_threshold`（默认 8px）+ 4px 余量，抖动不再吞点击；
  * 3.5s 安全超时 + "按键已松开"兜底，任何输入状态都能自恢复。
* 新增右键菜单：换一张壁纸 / 打开壁纸文件夹 / 剪贴板历史 / 重置悬浮球位置 / 锁屏。
* 剪贴板小按钮移出球的可点击区域（原位置与球重叠，抢占球右下角 1/4 的点击），
  并在打开前检查菜单状态，避免 toggle 到已经打开的菜单。
* 切换成功后球体 EASE_OUT_BACK 回弹反馈。

## 2. 顶栏文字自适应壁纸亮度（liquid-glass-react 的 overLight 思路）

* 扩展在每次换壁纸（含启动）时用 GdkPixbuf 采样壁纸顶部条带（顶栏所在区域）平均亮度；
* 亮度 > 0.58 时给 `#panel` 挂 `cw-light-wallpaper` 类，主题 CSS 自动把顶栏文字/图标
  换成深色 + 白色微光晕；暗壁纸则保持白字。不再固定白色。

## 3. 材质分层（对齐 Apple：模糊管可读性，边缘管"玻璃感"）

| 部位 | 背景 | 中心 | 边缘 | 备注 |
|---|---|---|---|---|
| Dock | 动态模糊（`static-blur=false`，实时采样 Dock 后面的窗口/应用内容） | `sigma: 4`，`brightness: 0.72`，中心尽量透明 | CSS 细白边 + 内高光 + 外泛光，动态层由 corner shader 裁圆角 | 不再用桌面壁纸副本伪装玻璃 |
| 顶栏 | 动态模糊 `sigma 3`（轻） | `brightness 0.78` + CSS `rgba(0,0,0,0.15)` | 主题原有样式 | 用户要求"加一点模糊让字清楚" |
| 快捷设置/菜单 | 动态模糊 `sigma 6`（磨砂） | `brightness 0.66` + CSS `rgba(12,14,20,0.36)` | 24px 圆角 + 1px 亮边 | "浑浊"材质适合承载文字的弹出层 |
| 应用 headerbar | GTK CSS（窗口自身半透明背景） | `rgba(13,17,26,0.40)` | 四向内高光 + 1px 顶缘亮边 | gtk-3.0/gtk-4.0 均已覆盖 |

## 4. 弹出菜单"尖尖"修复

`.popup-menu-boxpointer` 的 `-arrow-*` 全系清零（透明箭头、无边框、无阴影），
子菜单 `.popup-sub-menu` 独立圆角。圆角面板外不再有矩形/箭头残块。

## 5. blur-my-shell 定制版补丁（改动已同步 `blur-my-shell-patches/`）

* `conveniences/dynamic_corner.js`（新增）：把 corner.glsl 以最外层效果链到动态模糊层上，
  并随 allocation 同步宽高——GNOME 46 的 `Shell.BlurEffect` 只会画矩形模糊，
  补丁让 Dock/弹出层的模糊背景圆角与 CSS 圆角对齐。
* `components/popup/blur_surface.js`：动态路径挂载上述圆角辅助，destroy 时清理。
* `components/dash_to_dock.js`：
  * 动态路径同样圆角化；
  * 指针轮询改为**自适应间隔**：指针靠近 Dock 24ms（折射需要），离开后 250ms
    （原先常驻 42Hz 轮询，空耗 CPU、阻碍核显降频）。

## 6. 性能治理

* `system-monitor@gnome-shell-extensions`（gcampax 版）已禁用——与 Vitals 功能重复，双重轮询；
* `rounded-window-corners@fxgn` 失效条目已从 enabled-extensions 清除；
* CoverflowAltTab `_subSwitchers is null` 崩溃已加空值守卫（原先每次 Alt+Tab 都抛 JS 错误）；
* 主题 CSS 的 `-1px 1px 5px 0px`（含 spread 第 4 值）已修正，消除
  "Ignoring excess values in shadow definition" 日志刷屏；
* Dock 指针轮询自适应化（见上）。

若浏览器滚动仍偶发卡顿，按以下顺序排查：
1. 暂时禁用 `rounded-windows@marcosgt.github.io`（X11 全窗口着色器，本轮保留未动，
   因为禁用后窗口失去圆角）对比；
2. 关闭 runcat（常驻面板动画，阻碍 GPU 空闲）；
3. 顶栏动态模糊如果感觉拖慢全屏拖动，可 `gsettings set
   org.gnome.shell.extensions.blur-my-shell.panel blur false` 单独关闭。
