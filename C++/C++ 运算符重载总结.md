# C\+\+ 运算符重载 系统总结

## 一、核心本质

运算符重载就是**给 C\+\+ 已有的运算符，重新定义它作用于「自定义类对象」时的行为**。

- 只能重载**已存在**的运算符，不能创造新运算符；

- 只能用于**类 / 结构体对象**，不能修改 int、double 等内置类型运算符规则；

- 本质就是**函数重载**，运算符本质是特殊函数。

## 二、不能重载的运算符（必考）

`::`  `\.\*`  `\.`  `?:`  `sizeof`
这 5 个**绝对不能重载**。

## 三、两种重载形式

### 1\. 成员函数重载

- 隐含**左操作数**为当前对象 `this`

- 格式：`返回值 operator运算符\(右操作数\)`

```C++
class A {
public:
    A operator+(const A& b); 
};
// 使用：a + b  等价于 a.operator+(b)
```

### 2\. 全局友元函数重载

- 无隐含 this，**左右操作数都要显式传参**

- 适合：左操作数不是本类对象（如 `3 \+ 对象`）

- 核心特性：友元函数**能直接访问类的私有成员和保护成员**（无需通过类的公有成员函数间接访问），这是友元重载的重要优势，也是其核心作用之一。

```C++
friend A operator+(const A& a, const A& b);
```

### 3\. 补充：友元类（扩展知识点）

除了全局友元函数，运算符重载中还可能用到**友元类**，其核心特性与友元函数一致，可直接访问类的私有/保护成员，具体定义和用法如下：

- 定义格式：在类内部声明友元类，使用 `friend class 类名;`，声明位置可在公有、私有或保护区域（不影响访问权限）。

- 核心作用：当需要让一个类的所有成员函数，都能直接访问另一个类的私有/保护成员时，使用友元类（比逐个声明友元函数更简洁）。

- 注意事项：友元关系是**单向的**（如类B是类A的友元，类A不一定是类B的友元）、**不可传递**（类C是类B的友元，类B是类A的友元，类C不能直接访问类A的私有成员），且友元类不能继承。

```C++
class Point {
private:
    int x, y;
    // 声明FriendClass为Point的友元类
    friend class FriendClass;
public:
    Point(int x=0, int y=0) : x(x), y(y) {}
};

// 友元类：可直接访问Point的私有成员x、y
class FriendClass {
public:
    // 友元类中的成员函数，实现Point对象的+运算符重载
    Point operator+(const Point& p1, const Point& p2) {
        Point res;
        res.x = p1.x + p2.x; // 直接访问私有成员x
        res.y = p1.y + p2.y; // 直接访问私有成员y
        return res;
    }
};

// 使用示例
int main() {
    Point a(1,2), b(3,4);
    FriendClass fc;
    Point c = fc.operator+(a, b); // 调用友元类中的重载函数
    return 0;
}
```

补充说明：友元类在运算符重载中使用较少，通常用于复杂场景（如多个运算符需要访问私有成员，且逻辑关联紧密），日常开发中，全局友元函数更常用、更灵活。同时需牢记：友元关系具有单向性（仅声明方允许友元访问，反之不成立）和无传递性（间接友元无法访问私有成员），不可混淆。

## 四、运算符重载规则

1. **优先级、结合性、操作数个数**不能改；

2. 单目运算符重载后还是单目，双目还是双目；

3. 不能随意篡改语义，建议**保持原有语义习惯**（\+ 做加法、== 做比较）；

4. 赋值 `=`、下标 `\[\]`、括号 `\(\)`、箭头 `\-\&gt;` **只能用成员函数重载**，不能用友元。

## 五、常用运算符重载分类

### 1\. 双目算术：\+ \- \* /

一般返回**新对象**，不修改自身。

### 2\. 赋值运算符 =

必须成员重载，**深拷贝专用**，防止浅拷贝内存泄漏。

### 3\. 关系运算符 == \!= \&gt; \&lt;

返回 `bool`，只做成员比较判断。

### 4\. 单目运算符 \+\+ \-\-

分**前置**、**后置**：

- 前置：`operator\+\+\(\)`

- 后置：`operator\+\+\(int\)` 占位参数

### 5\. 输入输出 \&gt;\&gt; \&lt;\&lt;

**只能全局友元**，因为左操作数是 `cin/cout` 不是自定义类。

### 6\. 下标 \[\]、括号 \(\)、箭头 \-\&gt;

只能成员重载，常用于容器、仿函数、智能指针。

## 六、关键易错点

5. 成员重载**左操作数必须是本类对象**；友元无限制（含友元函数、友元类），且友元能直接访问类的私有/保护成员；同时注意：友元关系是单向的、无传递性。

6. 重载 `\+\+/\-\-` 后置必须加 `int` 形参（仅占位）。

7. `\&lt;\&lt; \&gt;\&gt;` 必须用友元，不能写成成员函数。

8. 重载运算符尽量**const 修饰形参和成员函数**，保证只读不修改。

9. 返回值尽量用**引用 \&amp;** 减少拷贝（算术运算除外，要返回临时对象）。

## 七、运算符重载函数的返回值类型（核心答疑）

运算符重载本质是函数，返回值类型**没有固定唯一值**，完全由运算符语义、使用场景和性能需求决定，核心遵循“贴合原有运算符用法、避免不必要拷贝、保证链式调用”原则，不同类型运算符对应固定的标准返回值，具体分类如下：

### 1\. 算术运算符（\+、\-、\*、/、%）—— 返回**类的新对象**

这类运算符是**只读运算**，不修改原操作数，需要计算后生成全新对象返回，绝对不能返回引用（临时对象生命周期短，返回引用会悬空）。

```C++
// 标准写法：返回当前类的新对象
class Point {
public:
    int x, y;
    // 成员函数重载+，返回Point新对象
    Point operator+(const Point& other) const {
        Point res;
        res.x = this->x + other.x;
        res.y = this->y + other.y;
        return res;
    }
};
```

### 2\. 赋值类运算符（=、\+=、\-=、\*=、/=）—— 返回**类的引用**

这类运算符会**修改当前对象自身**，返回当前对象的引用，核心目的是支持**链式赋值**（如 a = b = c），同时避免拷贝提升性能，且只能用成员函数重载。

```C++
// 赋值运算符=，返回Point&引用
Point& operator=(const Point& other) {
    if (this == &other) return *this; // 防止自赋值
    this->x = other.x;
    this->y = other.y;
    return *this; // 返回当前对象的引用
}
// 复合赋值+=，同理返回引用
Point& operator+=(const Point& other) {
    this->x += other.x;
    this->y += other.y;
    return *this;
}
```

### 3\. 关系/逻辑运算符（==、\!=、\&gt;、\&lt;、\&gt;=、\&lt;=、\!）—— 返回**bool类型**

这类运算符用于判断真假，完全贴合内置类型用法，固定返回bool值，无特殊场景无需修改，成员函数重载时建议加const修饰，保证不修改原对象。

```C++
bool operator==(const Point& other) const {
    return (this->x == other.x) && (this->y == other.y);
}
bool operator<(const Point& other) const {
    return this->x < other.x;
}
```

### 4\. 单目自增自减运算符（\+\+、\-\-）—— 前置返回**引用**，后置返回**新对象**

前置\+\+/\-\-：先修改自身，再返回修改后的对象引用，支持链式操作；后置\+\+/\-\-：先保存原对象值，再修改自身，最后返回保存的原对象（临时对象，不能返回引用）。
**编译器区分前置、后置\+\+/\-\-的核心方式：通过函数参数的差异**—— 后置重载函数会增加一个**无实际意义的int类型占位参数**，前置重载函数无此参数，编译器通过“是否有int占位参数”直接区分两者，具体细节如下：

- 前置\+\+/\-\-：函数原型无int参数，格式为 `返回值类型 operator\+\+\(\)`（如文档中 `Point\&amp; operator\+\+\(\)`）；

- 后置\+\+/\-\-：函数原型必须加int占位参数（仅用于区分，无需传递实际值），格式为 `返回值类型 operator\+\+\(int\)`（如文档中 `Point operator\+\+\(int\)`）；

- 补充说明：这个int占位参数不参与任何运算，仅作为“编译器识别标记”，比如调用 `a\+\+` 时，编译器会自动匹配带int参数的重载函数，调用 `\+\+a` 时匹配无int参数的函数，无需程序员手动区分。

```C++
// 前置++，返回引用
Point& operator++() {
    this->x++;
    this->y++;
    return *this;
}
// 后置++，int为占位参数，返回新对象
Point operator++(int) {
    Point temp = *this; // 保存原值
    this->x++;
    this->y++;
    return temp;
}
```

### 5\. 输入输出运算符（\&gt;\&gt;、\&lt;\&lt;）—— 返回**流对象引用**

左操作数是cin/cout流对象，必须用友元重载，返回istream/ostream引用，支持链式输入输出（如 cout \&lt;\&lt; a \&lt;\&lt; b）。

```C++
friend ostream& operator<<(ostream& os, const Point& p) {
    os << "x:" << p.x << ", y:" << p.y; // 直接访问私有成员x、y（若x、y为私有）
    return os;
}
friend istream& operator>>(istream& is, Point& p) {
    is >> p.x >> p.y; // 直接访问私有成员，无需通过公有接口
    return is;
}
```

### 6\. 下标、箭头、函数调用运算符（\[\]、\-\&gt;、\(\)）—— 按需求返回成员/对象/bool

\[\]：常返回成员变量的引用，支持读写（如 arr\[0\] = 1）；
\-\&gt;：返回对象指针或对象引用，用于智能指针；
\(\)：返回值自定义，可做仿函数使用。

**核心速记**：只读运算返新对象，修改自身返引用，判断真假返bool，输入输出返流引用，自增前后分对象和引用。

## 八、一句话极简概括

运算符重载就是**把运算符当成函数，给类对象定制运算规则，有成员、友元（友元函数、友元类）两种写法，受限固定运算符数量和语法规则，常用来自定义对象加减、比较、读写、下标操作**；需注意友元关系是单向的、无传递性。
